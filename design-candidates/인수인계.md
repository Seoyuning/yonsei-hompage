연세대학교 기계공학부 홈페이지 인수인계서
팀 Gear-Up


이 제출물은 웹사이트 아홉 쪽과, 화면 위에서 내용을 바로 고치는 온라인 편집기를
한 벌로 묶은 것입니다. 이 문서만 따라 하시면 배포와 편집이 모두 가능합니다.


1. 폴더 구성

   H-academic.html      메인
   G-about.html         학부 소개, 교육목표, 조직, 연혁, 오시는 길
   G-people.html        교수진, 교직원, 동문
   G-research.html      연구 비전, 연구 분야, 연구실, 홍보영상, 대외협력
   G-academics.html     교육과정, 이수 체계도, 졸업 요건, 전공 교과, 동아리
   G-graduate.html      대학원 입학, 졸업 요건, 교과목, 연구실, BK21
   G-news.html          공지, 뉴스, 세미나, 학사 일정, 학위논문심사, 자료실, 취업
   G-admissions.html    학부 입학, 대학원 진학, 장학, FAQ
   index.html           메인으로 보내는 진입점

   assets/js/data.js    사이트의 모든 내용이 이 한 파일에 담겨 있습니다
   assets/nav.js        상단 바, 형제 탭, 푸터, 로딩 표시 (아홉 쪽 공통)
   assets/i18n/en.json  한국어와 영어를 잇는 사전
   assets/studio/       온라인 편집기
   api/                 편집기의 서버쪽 기능입니다 (저장, AI 도우미)
   vercel.json          경로 규칙, 보안 헤더, 캐시 설정
   STUDIO_SPEC.md       편집기 설계 계약서

   내용을 고치실 곳은 assets/js/data.js 한 곳입니다. 교수 서른세 분, 연구실
   서른세 곳, 학부와 대학원 교과, 공지와 세미나와 뉴스, 학사일정까지 모두 이
   파일에서 나옵니다. HTML 을 건드리지 않으셔도 내용이 바뀝니다.


2. 배포 없이 그냥 열어 보시는 방법

   파일을 두 번 눌러 여시면 브라우저 보안 정책 때문에 데이터가 읽히지 않습니다.
   반드시 아래와 같이 로컬 서버로 열어 주십시오.

       cd 이-폴더
       python3 -m http.server 8000

   그 뒤 브라우저에서 http://localhost:8000/H-academic.html 로 접속하시면 됩니다.
   이 상태로 모든 화면이 동작하며, 편집기의 저장 기능만 되지 않습니다.
   저장에는 서버가 필요하기 때문입니다.


3. 배포하시는 방법 (Vercel)

   첫째, 이 폴더를 GitHub 저장소에 올리십시오.
   둘째, vercel.com 에서 그 저장소를 Import 하십시오.
   셋째, Framework Preset 은 Other 로, Root Directory 는 이 폴더로 두십시오.
   넷째, 아래 환경변수를 Project Settings 의 Environment Variables 에 넣으십시오.

   배포만 하실 거라면 환경변수 없이도 됩니다. 편집기의 저장 기능을 쓰시려면
   필요합니다.

       PUBLISH_PASSCODE    편집자 공용 암호입니다. 반드시 필요합니다
       GH_TOKEN            GitHub fine-grained PAT 입니다.
                           이 저장소의 Contents 읽기·쓰기 권한만 주십시오
       GH_OWNER            저장소 소유자입니다 (예: todo0157)
       GH_REPO             저장소 이름입니다
       GH_BRANCH           배포 브랜치입니다 (예: main)
       GH_BASEPATH         저장소를 기준으로 한 이 폴더의 경로입니다
       GH_AUTHOR_EMAIL     선택 사항입니다. 커밋에 쓸 공용 메일 주소입니다
       GEMINI_API_KEY      선택 사항입니다. 편집기의 AI 도우미에 쓰입니다
       ANTHROPIC_API_KEY   위와 같은 용도이며, 둘 중 하나만 있으면 됩니다

   코드 안에는 열쇠가 하나도 들어 있지 않습니다. 전부 process.env 로만 읽으므로
   저장소를 공개하셔도 토큰이 새지 않습니다.


4. 온라인 편집기 사용법

   첫째, 아무 화면 주소 뒤에 ?studio=1 을 붙이십시오. 예를 들어
   https://…/H-academic.html?studio=1 과 같습니다. 푸터의 관리자 단추를
   누르셔도 같습니다.

   둘째, 암호와 본인 성함을 넣으십시오. 암호는 PUBLISH_PASSCODE 로 정해 두신
   값입니다.

   셋째, 화면의 글자를 그대로 누르셔서 고치시면 됩니다. 사진 교체와 한국어·영어
   사전 수정도 같은 자리에서 하실 수 있습니다.

   넷째, 저장을 누르시면 GitHub 에 커밋되고 Vercel 이 다시 배포합니다.

   편집하시는 분께는 GitHub 계정도 토큰도 필요하지 않습니다. 암호와 성함만
   있으면 됩니다. 토큰은 서버에만 있습니다. 누가 언제 무엇을 고쳤는지가 커밋으로
   남으므로 이전 상태로 되돌리시는 것도 가능합니다.


5. 사진과 글꼴의 라이선스

   출처 표시가 필요 없는 것으로 맞추었습니다. 공개 도메인과 CC0, Pexels
   자산입니다. 다만 마스코트 독수리 하나만 CC BY 4.0 이라 모든 쪽 푸터에
   저작자를 밝혀 두었으니 지우지 말아 주십시오.

   기록은 아래 파일들에 있습니다.

       assets/fields/LICENSE.txt        연구 분야 사진 여섯 장
       assets/HERO-LICENSE.txt          구성원 화면 배경
       assets/eagle-p-LICENSE.txt       마스코트 독수리 (CC BY 4.0, 표시 의무)
       assets/fonts/LICENSE.txt         JetBrains Mono (OFL 1.1)

   오픈소스 라이브러리는 아래 둘입니다.

       Pretendard 1.3.9    SIL OFL 1.1, 길형진(orioncactus)
                           한글 본문 글꼴이며 jsDelivr CDN 으로 불러옵니다
       JetBrains Mono      SIL OFL 1.1, JetBrains s.r.o.
                           영문 라벨과 번호에 쓰이며 저장소에 직접 실었습니다

   그 밖의 프레임워크나 아이콘 라이브러리는 쓰지 않았습니다. 화면의 모든 동작과
   아이콘 SVG 는 이 저장소 안의 자작 코드입니다.

   학교 자산에 관하여 말씀드립니다. 머리말의 교표와 연세대학교 기계공학부라는
   명칭은 학부 홈페이지 구축을 목적으로 한 본 경진대회 출품작의 범위 안에서만
   썼으며, 변형이나 재배색 없이 원본 비율 그대로 두었습니다. 채택되어 공식
   홈페이지로 발전할 경우에는 학교 UI/BI 가이드라인에 맞추어 규격을 다시
   맞추셔야 합니다.

   교수 사진 서른세 장과 동아리 포스터 네 장은 학부가 이미 공개한 자료에서
   옮긴 것입니다. 학부 홈페이지 밖의 용도로는 쓸 수 없습니다.


6. 내용을 채울 때 지킨 원칙

   이 사이트의 글과 수치는 학부 공식 홈페이지와 연세대학교 공식 학사일정에서
   옮긴 것입니다. 없는 사실을 지어내지 않았고, 확인되지 않은 것은 싣지
   않았습니다.

   공지 본문 가운데 안내문이 이미지나 PDF 로만 되어 있는 글은 원문에서 보시라고
   안내합니다. 남의 서버에 있는 이미지를 끌어다 쓰지 않았습니다.

   대외협력에 적힌 기업과 기관은 학부 게시판에 실제로 공고를 올린 곳만
   적었습니다. 협약을 맺었다고는 쓰지 않았습니다.

   동문 인터뷰와 발전기금은 화면 구성을 위한 예시임을 화면에 그대로 표시해
   두었습니다. 실제 동문 정보는 학부에서 확인하신 뒤 등재하시면 됩니다.

   이어서 고치실 때에도 같은 기준을 지켜 주시기를 부탁드립니다.
