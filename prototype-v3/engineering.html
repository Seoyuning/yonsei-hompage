§01 / 스택

기술 스택 — 의존성 0

순수 HTML · CSS · Vanilla JS. 프레임워크·빌드 도구·트래커·쿠키가 없어 file://로 직접 열립니다.

이 사이트는 런타임 의존성이 0입니다. package.json 자체가 없고, 외부에서 불러오는 것은 오픈 라이선스 서체(CDN) 뿐입니다. 모든 인터랙션(테마·검색·모바일 메뉴·리빌)은 한 개의 클래식 <script defer>가 처리하며, JS가 꺼져도 본문과 링크는 html.js 게이팅으로 항상 보입니다.

C — 12컬럼 비대칭 그리드 · 컨테이너 쿼리

레이아웃은 12컬럼 그리드 위에서 7+5 · 5+7 · 8+4로 뒤집으며 리듬을 만듭니다. 전 요소 중앙정렬을 금지하고 좌측 정렬을 기본으로 삼아, 잡지 조판의 긴장감을 유지합니다. 48rem 미만에서는 축소가 아니라 1열 재구성으로 전환됩니다.

교수 카드 등 반복 컴포넌트는 컨테이너 쿼리로 조판합니다. 뷰포트가 아닌 부모의 폭을 기준으로 좁으면 세로, 넓으면 가로로 스스로 재배치되어, 어떤 컬럼에 놓이든 정상 작동합니다. 미지원 브라우저는 @supports 폴백으로 동일 레이아웃을 보장합니다.

  • 공지·뉴스·세미나 — posts[]에 source·verifiedAt 필수.
