# 연세대학교 기계공학부 홈페이지 — 인수인계

팀 DATUM 제출물. **웹사이트 여덟 쪽 + 화면에서 바로 고치는 온라인 편집기**가 한 벌로 들어 있습니다.
이 문서만 따라 하면 배포와 편집이 됩니다.

## 2. 그냥 열어 보기 (배포 없이)

파일을 두 번 눌러서 열면 브라우저 보안 정책 때문에 데이터가 안 읽힙니다.
**로컬 서버로 열어야 합니다.**

```bash
cd 이-폴더
python3 -m http.server 8000
```
→ 브라우저에서 `http://localhost:8000/H-academic.html`

이 상태로 모든 화면이 동작합니다. 편집기의 **저장**만 되지 않습니다(서버가 필요).

---

## 3. 배포하기 (Vercel)

1. 이 폴더를 GitHub 저장소에 올립니다.
2. [vercel.com](https://vercel.com) 에서 그 저장소를 Import 합니다.
3. **Framework Preset: Other**, **Root Directory: 이 폴더**로 둡니다.
4. 아래 환경변수를 넣습니다 (Project Settings → Environment Variables).

배포만 할 거면 환경변수 없이도 됩니다. **편집기의 저장 기능을 쓰려면** 필요합니다.

| 변수 | 설명 | 예 |
|---|---|---|
| `PUBLISH_PASSCODE` | 편집자 공용 암호. **필수** | 팀에서 정한 문자열 |
| `GH_TOKEN` | GitHub fine-grained PAT. 이 저장소 **Contents: read/write** 만 | `github_pat_…` |
| `GH_OWNER` | 저장소 소유자 | `todo0157` |
| `GH_REPO` | 저장소 이름 | `yonsei-me-homepage-competition` |
| `GH_BRANCH` | 배포 브랜치 | `main` |
| `GH_BASEPATH` | 저장소 기준 이 폴더 경로 | `design-candidates` |
| `GH_AUTHOR_EMAIL` | (선택) 커밋에 쓸 공용 메일 | |
| `GEMINI_API_KEY` 또는 `ANTHROPIC_API_KEY` | (선택) 편집기의 AI 도우미 | |

> **코드 안에 열쇠는 하나도 없습니다.** 전부 `process.env` 로만 읽습니다.
> 저장소를 공개해도 토큰이 새지 않습니다.

---

## 4. 온라인 편집기 쓰는 법

1. 아무 화면 주소 뒤에 **`?studio=1`** 을 붙입니다.
   예: `https…/H-academic.html?studio=1`
   (푸터의 「관리자」를 눌러도 같습니다.)
2. 암호(`PUBLISH_PASSCODE`)와 본인 이름을 넣습니다.
3. 화면의 글자를 그대로 눌러 고칩니다. 사진 교체, 한/영 사전 수정도 됩니다.
4. **저장**을 누르면 GitHub 에 커밋되고, Vercel 이 다시 배포합니다.

편집자는 GitHub 계정도 토큰도 필요 없습니다. **암호와 이름만** 있으면 됩니다.
토큰은 서버에만 있습니다.

## 6. 내용을 고칠 때 지킨 원칙

이 사이트의 글·수치는 **학부 공식 홈페이지와 연세대 공식 학사일정에서 옮긴 것**입니다.
없는 사실을 채워 넣지 않았고, 확인되지 않은 것은 싣지 않았습니다.

- 공지 본문 중 안내문이 이미지·PDF 로만 된 글은 「원문에서 보라」고 안내합니다
  (남의 서버 이미지를 끌어다 쓰지 않았습니다).
- 대외협력의 기업·기관은 학부 게시판에 **실제로 공고를 올린 곳**만 적었습니다.
  「협약을 맺었다」고는 쓰지 않았습니다.

이어서 고치실 때도 같은 기준을 지켜 주시면 좋겠습니다.
