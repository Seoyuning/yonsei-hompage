## 1) Executive Summary — 1등 전략 한 페이지

### 승리 공식 (한 문장)
> 이건 디자인 콘테스트가 아니라 **학부 공식 홈페이지 조달(B2B 도입) 심사**다. 심사위원=학부 교수진은 "예쁜 학생작"이 아니라 **"월요일에 me.yonsei.ac.kr을 이걸로 바꿔도 우리가 안전하게 운영할 수 있는 사이트"**를 산다. → **느끼게(B) → 믿게(A) → 떨어뜨릴 구실 안 주기(C)** 의 3단계를 각기 다른 무대 장면으로 정조준해, 위원회가 만장으로 채택을 결심하게 만든다.

### 핵심 차별점 5축 (경쟁작이 구조적으로 못 하는 것)
1. **실데이터 100% (해자)** — 교수 33·연구실 33을 실명·직위·이메일·전화·랩URL·국영문명으로 완전 충전 + 4-way 교차링크. AI·템플릿이 3.5주에 단축 못 하는 유일 항목. **가설 B(교수가 자기 이름 검색)의 무대 장치.**
2. **채택가능성 (결승점)** — Keystatic CMS로 조교가 코드 0줄 운영 + 정적 export로 학교 인프라 이양 + 핸드오프 6종 문서. **가설 A.**
3. **무결성 (탈락-스크린 통과)** — KWCAG 2.2 AA·모바일 Lighthouse 고득점·라이선스 무하자를 `/공학` 페이지가 커밋 해시로 자가 증명. **가설 C.**
4. **ME 정체성 시그니처** — 치수선·도면·기구 모션이 "연세 *기계*공학"을 0.5초 각인. 템플릿/v0가 못 흉내내는 도메인 지식.
5. **i18n + 성능** — 진짜 구조적 한/영 패리티(현행 /me_en 분리 운영 폐기) + static-first 모바일 우위.

## 2) 포지셔닝 & 통합 컨셉

### 컨셉명·태그라인
- **「機制 · Mechanism in Motion」** (기제 = 작동원리)
- **KO:** "도면이 작동하기 시작한다 — 연세 기계공학, 멈추지 않는 정밀."
- **EN:** "Where the blueprint begins to operate — measured, operable, unstoppable."
- **B2B 서브카피(발표·히어로):** "학생 작품이 아니라, 내일 띄울 — 작동하고(motion)·출처가 달렸고(evidence)·졸업해도 안 죽는(ops) 우리 학부의 사이트."

### 통합의 한 줄 논리 — 모든 것이 **치수선(dimension line) 한 원소**에서 파생
다섯 가치가 한 획에서 나오므로 이식이 *장식이 아니라 증폭*이다:

| 치수선이 동시에 하는 일 | 흡수 가치 | 서브시스템 |
|---|---|---|
| 기구의 행정거리(stroke) 실시간 측정 | motion | **機制 척추** |
| 그 수치에 출처·최종확인일 각인 | evidence | **DATUM 계측층** |
| 사이트 자신의 사양을 주석(`LCP├─0.8s─┤`) | excellence | **/공학 사양서** |
| 한 사람의 궤적 마일스톤에 틱 | people | **사람이 동력** |
| 그 수치가 곧 `/admin`의 편집 필드 | ops | **운영본** |

→ 사이트 전체가 "한 장의, 작동하고, 출처가 달리고, 자기 사양을 재며, 사람이 동력이고, 조교가 코드 없이 고치는 거대한 공학 도면"이다.

### 정당성 앵커 (불변 — 교수 공감 트리거)
학부 연구 모토가 이미 **"멈추지 않는 50년, 100년을 향한 도전"**(research.do 실측). 모션은 외부 장식이 아니라 **학부가 스스로 쓴 '멈추지 않는'을 화면 위 물리로 구현**한 것. 정당성을 학부 콘텐츠에서 조달한다.

### 5대 디자인 원칙
1. **증거대상 필수** — 움직이면 실재 ME 개념(치수선·자유물체도·기구학 링키지·응력장·유선)을 가리키고, 수치가 드러나면 출처·최종확인일을 단다. 장식 모션 0, 출처 없는 통계 0.
2. **정중동(靜中動) 게이팅** — 유휴=정지 도면. 모션은 스크롤·호버·포인터 의도에만. 자동재생 루프 0. `prefers-reduced-motion`=*열화 아닌 완성된 정적 도면*.
3. **하나의 도면 시스템** — 치수선·12-col 모눈·모노스페이스를 8개 콘텐츠 영역 전부에 동일 적용(=눈에 보이는 디자인 시스템 → 일관성 만점).
4. **사람이 동력이다** — 차가운 블루프린트를 실제 얼굴(동의 기반)·페이퍼톤·절제된 금색으로 상쇄. 교수=존중받는 서사 페이지.
5. **무결이 빌드에서 강제된다** — Lighthouse CI·axe·html-validate 게이트가 미달 시 배포 차단, 그 산출 JSON이 `/공학`의 데이터원.

## 4) 디자인 시스템 요약

> 원칙: 모든 토큰·컴포넌트는 "작동하는 공학 도면"(치수선·모눈·모노스페이스) 단일 시각 DNA에서 파생. 장식이 아니라 점수.

### 4.1 컬러 토큰 (핵심 발췌)
연세 블루+페이퍼톤이 화면 **90% 지배**. 금색=엠블럼 연계·대형텍스트·궤적노드 **전용(면적≤5%, 본문 금지)**. 보라/네온/글래스모피즘 HEX는 **팔레트에 존재하지 않음**(AI 슬롭 구조 차단).

```css
--blue-700:#103F8F;  /* 링크 (AA on white ~7:1) */
--paper-0:#FBFAF7; --paper-50:#F5F3EC;        /* 블루프린트 용지 */
--text-primary:#14181F;                        /* on paper ~16:1 */
--ink-line:#B7BEC9; --ink-grid:#E7EAF0;        /* 치수선·모눈 */
--gold-600:#8A6D2E;  /* 소형텍스트 허용선 AA~4.7:1 */ --gold-500:#B8954A; /* 장식/≥24px */
```

### 4.2 타이포 — "이 학부는 측정한다" 타이포 서명

### 4.3 형태 언어 — "도면은 선으로 정의된다"
라운드 기본 2~4px(**16~24px 둥근 카드 금지**=AI 슬롭 신호). Elevation=**보더-퍼스트**(섀도는 호버·팝오버만). 8px 베이스 스페이싱, 터치타깃 ≥44px. 모든 카드는 공통 `Card` 셸 상속(일관성 강제). Tailwind 임의값(`[#xxx]`) 린트 차단.

## 5) 기술 아키텍처 & 유지보수/CMS (콘텐츠옵스)

### 5.1 한 줄 아키텍처
**Astro 5 (static-first, islands) + TypeScript strict + Content Layer(YAML/MDX, Zod) + Keystatic(Git CMS) + Pagefind(정적검색) + Vercel(+정적 export 이양) + GitHub Actions 품질게이트.**

### 5.2 5대 원칙
① 정적이 디폴트, JS는 섬만(콘텐츠 페이지 JS 0KB → 모바일 구조적 우위). ② 단일 진실원천 `src/data/`(손수 HTML 0건). ③ 빌드가 사양·정확성·접근성 강제(Zod 위반·깨진 링크·LH 미달·axe 위반=배포 차단). ④ 벤더 락인 0(`output:'static'`→어떤 호스팅에도 재탑재). ⑤ 자기계측 정직성(CI 실측+커밋해시만).

### 5.3 Astro 확정 근거 (vs Next.js)
콘텐츠 페이지 **JS 0KB → 모바일 4×100 자명**(Next RSC baseline 80~100KB+에서 4×100 일관 달성 난이도↑) · 정적 export 1급 시민(이양) · Content Layer+Zod 네이티브 · 시그니처는 필요한 섬만 하이드레이션. 동적 서버·인증·실시간이 핵심일 때만 Next가 이기는데 **여긴 그게 없다**. (안전망: 추후 동적 위젯 필요 시 Astro **Server Islands**로 해당 컴포넌트만.)

### 5.4 저장소 구조 + Zod 거버넌스
```
src/data/{professors,labs,courses}/*.yaml  posts/*.mdx  engineering/{lighthouse,axe,build}.json
src/content.config.ts  keystatic.config.ts  astro.config.mjs  lighthouserc.cjs
.github/workflows/quality-gate.yml  docs/handoff/*
```
**Zod 스키마 하나가 거버넌스를 컴파일러로 만든다:** 이메일/전화 형식 오류·깨진 lab 참조 = **빌드 실패**; `_provenance{source, verifiedAt}` 누락 = **빌드 실패**(출처스탬프 자동화); `photoConsent:false` = 사진 미렌더; `clusters` = 교수·랩·과목·뉴스 4-way 교차링크+검색필터 공통 키. **placeholder 0건이 "정신"이 아니라 "컴파일러"가 된다.**

### 5.5 ★ 콘텐츠옵스 — Keystatic (D2 확정)
Astro Content Collection과 **스키마 단일 정의(드리프트 0)**. `/admin` WYSIWYG로 비개발자 편집 → GitHub 커밋 → Vercel 빌드.
- **컬렉션 = IA 노드 1:1:** posts(공지/뉴스)·professors·labs·courses. 마크다운 지식 불요(표·이미지·링크 WYSIWYG). 필수 필드·출처일 비우면 **저장 단계에서 막힘**.
- **권한 2-Tier (GitHub 역할+브랜치 보호):** **Tier1**(행정팀·조교) = posts/professors/labs WYSIWYG·코드 0줄·main 직접 커밋. **Tier2**(정보화팀·외주) = 구조·디자인은 Git PR(리뷰 필수). → 읽는 동선이 곧 운영 권한 지도.
- **일상 워크플로(조교, 코드 0줄):** 로그인(학교 GitHub OAuth) → 편집 → ⒜폼 내 즉시 미리보기 / ⒝브랜치 저장→Vercel Preview URL → 저장(main 커밋) → **CI 게이트 통과해야만 production** → **~1분 후 production+Pagefind 반영** → 롤백=커밋 Revert 1클릭.
- **오프라인 무대 데모:** Keystatic **local 모드**(GitHub 없이 로컬 파일 직접 편집) → 스테이지 와이파이 독립.

### 5.6 렌더링·배포·보안
전 페이지 SSG(`output:'static'`, ISR 불요 — 콘텐츠 소스가 Git이라 변경=커밋=리빌드). **서버 런타임 0 = 500 구조적 불가, Git 이력=즉시 롤백.** Vercel(Preview/Production), 정적 export로 학교 nginx/Cloudflare/Pages 재탑재. **쿠키리스 분석**(Vercel Web Analytics+Speed Insights → 동의배너 불요, RUM을 `/공학` field 데이터로). 보안헤더(`vercel.json`): CSP(`script-src 'self'`)·HSTS·nosniff·`X-Frame-Options:DENY`.


### 5.8 성능 예산 (게이트 강제)
LCP<1.0s(상한1.2) · CLS<0.01(0.02) · INP<100/TBT≤150ms · 홈 JS~0KB(≤50) · 그래프 라우트 JS≤120KB(lazy) · 페이지≤600KB. **히어로=인라인 SVG<15KB+서브셋폰트 preload(Three.js 미사용→LCP보호)**, 이미지 AVIF→WebP `astro:assets`, 폰트 unicode-range subset·`size-adjust`로 CLS 0.

## 6) 시그니처 기능 (창의성)

> 공통 규약(4기능 강제 상속, 위반 시 머지 불가): **R1 지시대상 필수** · **R2 정중동 게이팅(자동재생 0)** · **R3 빌드타임 안착**(그래프/DAG 좌표 빌드 시 JSON 동결→첫 페인트는 정적 SVG, JS-off·SR 안전) · **R4 정직 계측**(수치=CI JSON 주입, 리터럴 금지).

### ◆ 시그니처 ① 히어로 「작동하는 도면」 (P0) — motion·evidence·excellence 동시
- **상태기계:** 로드(0~0.8s) 연세블루 선으로 **슬라이더-크랭크 기구** 제도(SVG `stroke-dashoffset`, <15KB 무라이브러리, 헤드라인=실모토) → 정지(인쇄 도면) → 스크롤 스크럽(스크롤재킹 0).
- **물리(동역학 교수가 본다):** `x(θ)=r·cosθ+√(L²−r²·sin²θ)`, **stroke=2r 불변 datum**. 치수선이 행정거리를 모노 숫자로 실시간 측정. 정당성=전공필수 **MEU2650 동역학** + 송순호 내연기관 연구실(cleanenergy).
- **datum 5종:** `교수 33·연구실 33·6 클러스터·130 학점·since 1962`, 각 호버→출처패널, 클릭→해당 페이지 라우팅.
- **사양칩 3:** Lighthouse·LCP·a11y(CI JSON 주입) → `/공학` 라우팅.
- **폴백:** reduced-motion=치수 주석 완비 정적 완성 기구도(정보 완결). LCP=텍스트 헤드라인.
- **구현:** SVG 150줄+JS 120줄, 무라이브러리, 2~3일.

### ◆ 시그니처 ② 「학부라는 기구」 연구 지식그래프 + 교수 본인검색 킬샷 (P1) — motion·people·evidence
- **노드 72**(6클러스터+교수33+랩33), 엣지 66(실데이터 JSON). **물리=질량-스프링-감쇠**(velocity-Verlet 적분) → 캡션 `m·ẍ+c·ẋ+k·x=0 — MEU2650이 이 화면을 작동시킵니다` = **사이트가 자기 작동원리를 학부 교과로 주석**(전 세계 어느 ME 사이트에도 없는 자기참조 시그니처).
- **킬샷:** 검색→본인 노드 점등→클릭 시 카드가 아니라 **존중받는 스토리 페이지**(증명사진 또는 연세블루 모노그램 아바타 + "저는 ○○를 연구합니다, 왜냐하면…" + 랩 + 담당 교과목 + 최근 공지, 전 항목 출처 스탬프).
- **폴백:** canvas force-graph IO 지연로드, 소형/reduced-motion → 탭형 클러스터 리스트/아코디언+ARIA(검색·교차링크·출처스탬프 유지, 모션만 손실). 시뮬 ~8KB, d3 미채택(BOM 청결).
- **구현:** 시뮬 ~100줄+캔버스, 3~4일.

### ◆ 시그니처 ③ 「동력전달」 교과목 기구학 맵 (P2) — motion+콘텐츠+창의
선수→후수 **DAG**(위상정렬, x=학년). 확정 8노드(전공필수): MEU2600 고체역학·MEU2610 열역학·MEU2640 유체역학·MEU2650 동역학·MEU2104/MEU3005 실험1·2·MEU4300 창의제품설계(캡스톤)·MEU4400 학사논문. 과목 hover→후속 의존이 **동력전달처럼 순차 점등(CSS만)**. 노드색=6클러스터→"관심분야→들을 과목→그 연구실" 동선. 폴백=시맨틱 `<table>` 선수관계. 정적 SVG, 거의 0 비용.

### ◆ 시그니처 ④ 「자기계측」 `/공학` 사양서 (P1) — excellence·ops, 무대 클로저
4블록: ⒜성능·접근성 실측표(항목·사양·실측·**안전계수 ×3.1**·측정도구·**commit hash·측정일시**) ⒝BOM(스택·오픈소스 라이선스·폰트/에셋 출처) ⒞KWCAG/WCAG 2.2 AA 자가적합성+**axe 0위반** ⒟운영·인수 패키지 링크. **honesty: 빌드 실측·커밋 스탬프만, 하드코딩 희망수치 0**(자기참조 페이지 날조=자멸).

### 한 줄 결론
경쟁작은 성능을 *말하고* 모션을 *떡칠*하며 컴플라이언스를 *미루고* 핸드오프를 *안 낸다*. 이 플레이북은 **사이트가 자기 도면을 작동시키고(motion)·모든 수치에 출처를 달고(evidence)·사람을 동력으로 세우고(people)·자기 사양을 스스로 측정해 보여주며(excellence)·조교가 코드 없이 내일 띄우는 운영본(ops)**을 — 치수선 한 원소로 통합해 판다. 교수가 채택을 거부할 모든 이유를 컨셉의 구조 자체로 제거하는 것이 1등 확정 전략이다.
