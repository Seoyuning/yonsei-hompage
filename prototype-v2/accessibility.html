접근성 선언 §90 ACCESSIBILITY

§90.1 선언

적합성 상태

연세대학교 기계공학부 웹사이트(프로토타입 v2)는 W3C 웹 콘텐츠 접근성 지침(WCAG) 2.2 레벨 AA를 목표 기준으로 설계·제작되었습니다.

현재 상태는 자가 평가 기준 부분 적합입니다 — A·AA 55개 성공 기준 중 자가평가 충족 37건, 도구·수동 검증 예정 6건, 해당 없음 12건. 제3자 인증이 아닌 자가 평가이며, 검증 예정 항목은 제출(배포) 전 도구 검사와 수동 감사로 확정합니다. 기준별 상세 평가는 공학 사양서 §90.3 체크리스트에 전부 공개되어 있습니다.

평가 방식: 자가 평가(설계 검토 + 수동 점검) · 평가일 2026-07-03 · 대상: prototype-v2 전 페이지

§90.2 기능

지원 기능

전 페이지에 공통 적용되는 접근성 기능입니다.

완전한 키보드 조작

검색·메뉴·드로어·테마 전환·출처 스탬프까지 전 기능을 키보드만으로 사용할 수 있습니다. 모달은 포커스 트랩과 ESC 복귀를 지원합니다.

Tab / Shift+Tab · ESC
본문 바로가기

모든 페이지 첫 탭에서 ‘본문 바로가기’ 링크가 나타나 반복되는 내비게이션을 건너뛸 수 있습니다.

SKIP LINK · 2.4.1
선명한 포커스 표시

키보드 포커스가 닿는 모든 요소에 3px 포커스 링이 표시됩니다. 포커스 순서는 시각적 순서와 일치합니다.

:focus-visible · 2.4.7
청사진(다크) 모드

우측 상단 토글로 밝은 제도지·어두운 청사진 테마를 전환할 수 있으며, 선택은 기기에 저장됩니다(서버 전송 없음).

localStorage: ysme-theme
모션 최소화 존중

OS의 ‘동작 줄이기’ 설정을 켜면 모든 애니메이션(제도 효과·카운트업·리빌·기구 작동)이 정적 완성형으로 대체됩니다. 자동재생 루프는 원래 0건입니다.

prefers-reduced-motion
텍스트 확대 대응

상대 단위 기반 반응형 설계로 200% 확대와 360px 소형 화면에서도 내용·기능 손실 없이 이용할 수 있습니다. 넓은 표는 표 안에서만 스크롤됩니다.

REFLOW · 1.4.4 / 1.4.10
스크린리더 지원

랜드마크·제목 위계·표 머리글·aria 상태(열림/눌림/현재 페이지)를 제공하고, 검색·필터 결과 수는 aria-live로 음성 통지됩니다.

ARIA · 4.1.2 / 4.1.3
통합 검색

어느 페이지에서든 Ctrl+K로 교수·연구실·공지·교과목·페이지를 검색해 바로 이동할 수 있습니다 — 마우스 없이도 사이트 전체가 두 번의 입력 거리입니다.

Ctrl+K · 2.4.5
넉넉한 터치 타깃

버튼·링크 등 인터랙티브 요소는 최소 44px 높이로 설계되어 WCAG 2.2 기준(24px)을 여유 있게 상회합니다.

44px ≥ 24px · 2.5.8

§90.4 한계·문의

알려진 제한사항과 문의처

알려진 제한사항 KNOWN LIMITATIONS · 정직 공개

  • 영문 콘텐츠 — 현재 KO/EN 전환은 내비게이션·푸터 등 사이트 크롬에만 적용됩니다. 본문 영문판은 준비 중이며, 전환 시 화면에 고지됩니다.
  • 도구 검증 전 항목 6건 — 명도 대비 실측(1.4.3, 1.4.11), 입력 목적 속성(1.3.5), 호버 콘텐츠 ESC 해제(1.4.13), 포커스 가림(2.4.11), 부분 언어 표시(3.1.2)는 자가 설계 반영 상태로, 제출 전 도구·수동 감사로 확정합니다. 상세: 공학 사양서 §90.3.
  • 프로토타입 단계 — 성능 실측값(Lighthouse 등)은 아직 게시하지 않았습니다. 미측정 수치를 게시하지 않는 것이 이 사이트의 원칙입니다.
