# 「機制 · Mechanism in Motion」 — 최종 통합 컨셉 (확정본)

> 우승 컨셉 **[motion]**을 척추로, 나머지 4개 컨셉의 '득점 부위'를 외과적으로 이식한 **단일 통합 컨셉**. 이식은 장식이 아니라 점수다: DATUM[evidence]의 *출처 스탬프*, Powered by People[people]의 *교수 스토리·궤적*, 운영본[ops]의 *채택·이양*, 사양서[excellence]의 *자기계측*을 각각 명확한 서브시스템으로 박았다. 이 문서가 이후 모든 설계(IA·디자인·구현·발표)의 기준이다.

---

## 0) 통합의 한 줄 논리 — 왜 이 5개가 '하나'로 합쳐지는가

다섯 컨셉은 사실 **하나의 원소**를 공유한다: **치수선(dimension line)**. 통합 컨셉의 모든 것은 이 한 획에서 파생된다.

| 치수선이 동시에 하는 일 | 흡수한 컨셉 |
|---|---|
| 기구의 **행정거리(stroke)를 실시간 측정** | [motion] 작동하는 도면 |
| 그 수치에 **출처·최종확인일을 각인**(`33 ↔ faculty_list.do · 2026.07.XX`) | [evidence] 출처 스탬프 |
| 사이트 **자신의 사양을 주석**(`LCP ├─0.8s─┤`) | [excellence] 자기계측 |
| 한 사람의 **궤적 마일스톤에 틱**(입학→졸업) | [people] 궤적 라인 |
| 그 수치가 곧 **`/admin`의 편집 가능한 한 필드** | [ops] 운영본 |

→ **사이트 전체가 "한 장의, 작동하고, 출처가 달리고, 자기 사양을 재며, 사람이 동력이고, 조교가 코드 없이 고치는 거대한 공학 도면"이다.** 다섯 컨셉이 한 원소로 환원되므로 이식이 이질적이지 않고 *증폭*된다. 이것이 단일 컨셉으로 합성되는 근거다.

## 1) 최종 컨셉명 + 태그라인

- **컨셉명:** **「機制 · Mechanism in Motion」** (기제 = 작동원리/메커니즘)
- **메인 태그라인 (KO):** **"도면이 작동하기 시작한다 — 연세 기계공학, 멈추지 않는 정밀."**
- **메인 태그라인 (EN):** **"Where the blueprint begins to operate — measured, operable, unstoppable."**
- **B2B 서브카피 (발표·히어로):** **"학생 작품이 아니라, 내일 띄울 — 작동하고(motion), 출처가 달렸고(evidence), 졸업해도 안 죽는(ops) 우리 학부의 사이트."**
- **정당성 앵커(불변):** 학부 연구 모토가 이미 **"멈추지 않는 50년, 100년을 향한 도전"**(research.do 실측)이다. 모션은 외부에서 입힌 게 아니라 **학부가 스스로 쓴 '멈추지 않는'을 화면 위 물리로 구현**한 것 — 정당성을 학부 콘텐츠에서 가져온다(교수 공감 트리거).

**서브시스템 명명(발표·문서에서 그대로 사용):** 機制(척추·작동) + **DATUM 계측층**(출처) + **사람이 동력**(얼굴·궤적) + **운영본**(이양) + **/공학 사양서**(자기증명).

## 2) 왜 이게 1등인가 — 채점자(학부 교수진) 관점 핵심 서사 (한 문단)

손실회피적인 교수 위원회의 의사결정 동선은 정확히 **느끼게(B) → 믿게(A) → 떨어뜨릴 구실 안 주기(C)**다. 이 통합 컨셉은 그 세 단계를 각기 다른 이식 부위로 정조준한다 — 심사위원이 **자기 이름을 검색하는 순간, 동역학(스프링-질량) 물리로 자기 노드가 점등하고(motion) 정확·존중받는 자기 스토리 페이지가 출처 스탬프와 함께 열린다(people+evidence)**: 이것이 "이 팀은 우리에 대해 진짜로 일했다"는 정서적 후크 B다. 이어 **무대에서 30초 만에 `/admin`으로 공지 1건을 올려 사이트·검색에 반영**시키며 "내일 띄울 운영본"임을 입증(ops)하고, 마지막으로 **`/공학` 페이지가 커밋 해시와 측정일시가 박힌 Lighthouse 4×100·접근성 0위반을 사이트 스스로 게시(excellence)**해, 교수가 작품을 떨어뜨릴 모든 구실(누가 고치나·데이터 진짜인가·느린가·접근성 소송·구식인가)을 사전에 제거한다(C). 즉 경쟁작이 '예쁜 빈 껍데기'를 낼 때, 이 컨셉은 **ME 교수가 평생 신뢰해온 단 하나의 언어 — 작동·계측·검증된 사양 — 으로 말하면서, 동시에 교수 본인을 주인공으로 세우는** 유일한 출품작이다. 1등은 "가장 화려한 팀"이 아니라 **"월요일에 me.yonsei.ac.kr을 이걸로 바꿔도 되겠다고 위원회가 만장으로 믿게 만든 팀"**이며, 이 컨셉은 그 믿음을 감정·이성·무결의 3층으로 동시에 박는다.

## 3) 5대 디자인 원칙

각 원칙이 **척추(motion) + 이식(graft)**를 동시에 진다.

**① 증거대상 필수 (Referent + Evidence Required) — 이 컨셉의 지문.**
화면의 모든 움직임은 실재 ME 개념(치수선·자유물체도·기구학 링키지·응력장·유선)을 가리키고, **수치를 드러내는 순간 그 수치는 출처·최종확인일을 단다.** 보라 그라디언트·떠다니는 파티클·장식 모션 0건, 출처 없는 통계 0건. → *움직이면 기계공학답고, 멈추면 출처가 남는다.* (motion 지시대상 + evidence 출처스탬프 융합)

**② 정중동(靜中動) 게이팅 — 절제가 폴백이 아니라 디폴트.**
기본/유휴는 **인쇄된 기술 도면처럼 정지**. 모션은 스크롤·호버·포인터 등 의도에만 발동, 자동재생 루프 0. `prefers-reduced-motion`은 *열화된 경험*이 아니라 **완성된 정적 도면**으로 떨어진다 → 교수가 두려워하는 '요란한 스타트업 랜딩' 정서를 구조적으로 차단. (motion 정중동)

**③ 하나의 도면 시스템 — 치수선·모눈·모노스페이스.**
12-col 모눈(engineering grid) 위에 콘텐츠가 도면처럼 정렬되고, **치수선이 섹션 구분·여백 주석·도판 콜아웃의 반복 모티프**로 8개 콘텐츠 영역 전부에 동일 적용(=눈에 보이는 디자인 시스템 → 일관성 만점 트리거). 과목코드(MEU2650)·전화·치수·좌표는 **모노스페이스(IBM Plex Mono)**로 = "이 학부는 측정한다"는 타이포 서명. (motion+evidence+excellence 공통 시각 DNA)

**④ 사람이 동력이다 — 얼굴과 궤적으로 온기 주입.**
살아있는 기계의 동력원은 사람이다. 차가운 블루프린트 리스크를 **연세 블루+페이퍼 90% 지배 위에 ⒜ 실제 얼굴(동의 기반) ⒝ 따뜻한 페이퍼 톤 ⒞ 엠블럼 연계 절제된 금색(대형 텍스트·궤적 노드 전용)** 으로 상쇄. 교수=한 사람의 *존중받는 서사 페이지*. (people 이식 — 차가움 방어 + 감정 후크)

**⑤ 모션·증거 예산 = 무결(Zero-defect)이 빌드에서 강제된다.**
SVG/CSS 우선, Three.js는 값할 때만, IO 게이팅·지연로드, 모바일 60fps, LCP 미차단. **GitHub Actions의 Lighthouse CI·axe-core·html-validate 게이트가 사양 미달 시 배포를 막고**, 그 산출 JSON이 곧 `/공학` 페이지의 실측 데이터원이다. 경쟁 모션작이 모바일 Lighthouse 50~70으로 무너지는 지점에서 **모바일 4×100을 지키는 모션** 자체가 차별점. (excellence QC게이트 + 가설C 무결 이식)

## 4) 기계공학 시그니처 모먼트 (화면 단위, 3개)

### ◆ 모먼트 1 — 히어로: "도면 → 작동 → 계측" (슬라이더-크랭크 × 출처스탬프 × 사양칩)
**한 화면이 motion·evidence·excellence를 동시에 진다.**
- **로드(motion):** 연세 블루 선으로 **피스톤-크랭크 기구(slider-crank)**가 제도되듯 그려진다(SVG `stroke-dashoffset` ~0.8s, <15KB, 무라이브러리). 동역학(전공필수 **MEU2650**)·내연기관 연구실(**송순호, cleanenergy.yonsei.ac.kr**)이 다루는 기계공학의 원형 기구 → 0.5초 만에 "기계공학" 각인. 오버레이 헤드라인 = 실 모토 **"멈추지 않는 50년, 100년을 향한 도전"**.
- **정지(정중동):** 다 그려지면 인쇄 도면처럼 멈춰 격을 유지.
- **스크롤 연동(motion+evidence):** 스크롤하면 크랭크가 회전·왕복하고 **치수선이 행정거리(stroke)를 모노 숫자로 실시간 측정**. 그 치수선 끝에 **학부 실측치 5종**이 datum으로 박힌다 — `교수 33 · 연구실 33 · 6 클러스터 · 130 학점 · since 1962`. **각 수치 호버/탭 → `출처: faculty_list.do · 최종확인 2026.07.XX` 패널 전개**(evidence 이식). `33` 클릭 → 교수 디렉터리, `6` 클릭 → 클러스터 그래프로 라우팅.
- **사양칩(excellence 이식):** 히어로 하단 라이브 칩 3개 `◷ Lighthouse 100·100·100·100` · `LCP 0.8s` · `접근성 위반 0`, 각각 **`/공학` 사양서로 라우팅**. 바늘 안착하듯 카운트업.
- **reduced-motion / LCP 보호:** 치수 주석이 달린 **완성 정적 기구도** — 그 자체로 정보 완결. 히어로는 CSS/SVG 고정으로 **LCP<1s 보호**(Three.js 미사용).

### ◆ 모먼트 2 — 연구 지식그래프 "학부라는 기구" → 교수 본인 검색 → 스토리 페이지
**motion·people·evidence 융합 / 발표 킬샷.**
- **그래프(motion):** 노드 = 6연구분야 + 교수 33 + 연구실 33, 엣지 = 소속/협력(실데이터 JSON). 정지 시 읽기 쉬운 안정 성좌로 수렴(정중동). 분야 호버 → **기어가 맞물리듯** 연결 노드가 스프링(질량-스프링)으로 당겨오고 나머진 후퇴 → *학부가 가르치는 동역학이 화면의 작동원리*(모션=교과).
- **킬샷(people+evidence 이식):** 심사위원이 본인 성함을 말함 → 검색 → **자기 노드 점등** → 클릭 시 카드가 아니라 **존중받는 교수 스토리 페이지**가 열린다: 증명사진 + *평이한 한국어 연구 한 문장*("저는 ○○를 연구합니다, 왜냐하면…") + 그의 연구실(예: **박노철 → optomecha.yonsei.ac.kr**) + 담당 교과목 + 최근 공지가 초점으로 모임. **모든 사실에 출처 스탬프.** 어떤 3D 토이도 못 이기는 '개인적 투자(내 페이지가 정확하고 멋짐 → 내 표)'.
- **모바일/접근성 폴백:** 그래프 = canvas force-graph 지연로드, 소형 화면·reduced-motion에서 **탭형 클러스터 리스트/아코디언 + ARIA 키보드 대체**로 자동 다운그레이드(검색·교차링크 유지).

### ◆ 모먼트 3 — `/공학` 사양서 + 라이브 운영본 (무대 클로저)
**excellence·ops 융합 / 채택 결정타.**
- **`/공학(Engineering · Spec Sheet)`(excellence):** 4블록 — ⒜ 성능·접근성 실측표(항목·사양·실측·**안전계수 ×3.1**·측정도구·**commit hash·측정일시**), ⒝ BOM(스택·오픈소스 라이선스·폰트/에셋 출처), ⒞ KWCAG/WCAG 2.2 AA 자가적합성 + **axe 0위반 리포트**, ⒟ 운영·인수 패키지 링크. **honesty 규약: 빌드 실측·커밋 스탬프만, 하드코딩 희망수치 0**(자기참조 페이지에서의 날조 = 자멸).
- **라이브 편집(ops):** *"교수님 성함 주시면 지금 공지 1건 올리겠습니다"* → `/admin`(Decap/Sveltia WYSIWYG) → 입력 → 저장 → Git 자동 커밋 → ~30~60초 후 **사이트·Pagefind 검색에 반영**. 우측 빌드 상태가 계측 게이지처럼 차오름. 교수가 보는 건 데모가 아니라 **자기 학부 사이트가 실시간 갱신되는 운영 현장**.

> *(보조 P2) 교과목 기구학 맵:* 전공필수 8과목(고체역학 MEU2600·열역학 MEU2610·동역학 MEU2650·유체역학 MEU2640·창의제품설계 MEU4300·학사논문 MEU4400 등)의 선수→후수를 **기구 동력전달처럼 점등**하는 방향성 그래프. 노드 색 = 6클러스터 → "관심분야 → 들을 과목 → 그 연구실" 동선 완성. (motion+콘텐츠+창의 동시 득점, 늦으면 정적 도식 폴백)

## 6) 채택 스토리 — 제출 다음날 '공식 운영 전환' 시나리오 (D+1 타임라인)

> 발표(8월 첫째주) 다음날, 학부가 "채택" 결정만 내리면 벌어지는 일. 이 구체성이 곧 ops 이식의 점수.

- **D+0 발표장:** 심사위원 성함으로 라이브 공지 1건 시연 완료 → 그 공지가 이미 라이브 URL에 살아있음. *"방금 그 URL은 지금 운영본입니다."*
- **D+1 오전 — 권한 분리 인계:** `/admin` 계정 2종 발급. **Tier 1(행정팀·조교)** = `posts`(공지/뉴스)·`professors`·`labs` WYSIWYG 편집(코드 0줄). **Tier 2(정보화팀/외주)** = Git PR로 구조·디자인. → IA 노드 = `/admin` 편집 컬렉션 1:1 매핑이라 *읽는 동선이 곧 운영 권한 지도*.
- **D+1 오후 — 조교의 첫 단독 운영:** 학사 담당(예: **정나경 skyice@yonsei.ac.kr**)이 `/admin`에서 신규 공지 작성·저장 → **Git 자동 커밋 → Vercel 자동 빌드(Lighthouse CI 게이트 통과) → ~1분 후 반영**. 거대 이미지·깨진 링크를 넣어도 **CI 게이트가 배포를 막음** = "엔지니어가 졸업해도 사양은 빌드가 지킨다."
- **D+2~3 — 도메인·데이터 이관:** 정적 export를 학교 정보화팀이 인수 → **me.yonsei.ac.kr DNS 연결 1장** + 현행 `.do`(faculty_list.do·lab2.do) 데이터 → `data/*.yaml` 이관 스크립트 제공. 영문(/en)·접근성·개인정보(이메일 마스킹/문의폼)까지 포함.
- **운영 모델(수치 입증):** Vercel 무료 + CMS 무료(Git) + Pretendard OFL + Pagefind(백엔드 0) → **호스팅비 ≈0원, 관리 서버·DB 0개**(Git 이력 = 백업·롤백). 벤더 락인 0 = 어떤 호스팅에도 재탑재 가능.
- **제출 산출물(디자인 산출물로 동봉):** ⒜ 1쪽 **운영 인수인계 매뉴얼**(공지 올리는 법·교수 추가법·배포법, 스크린샷) ⒝ 콘텐츠 스키마 문서 ⒞ 도입 로드맵 1장(데이터 이관·담당자 교육·도메인·비용). **운영 문서를 내는 팀은 거의 없다 = "학생 프로젝트→도입 가능 시스템"의 다리.**

→ *"졸업해도 안 죽는다."* 교수의 숨은 1순위 공포를 D+1 타임라인으로 사살.
