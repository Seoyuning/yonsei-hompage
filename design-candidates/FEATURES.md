# 연세대학교 기계공학부 홈페이지 — 우리만의 특징 정리

> 팀 Gear-Up · 관제(콘솔) 디자인 사이트(design-candidates/)의 차별화 포인트 모음.
> 공모전 발표·설명 자료로 활용. (라이브: https://yonsei-me-homepage.vercel.app/H-academic.html)

## 1. 첫인상 — 실제로 돌아가는 3D 기계

- **절차적 3D 유성기어** (`assets/gear3d.js`, Three.js 로컬 번들): 모델 파일 없이 코드로 생성한
  태양기어·유성기어 3개·내접 링기어·캐리어. **실제 유성기어 운동학**(링 고정·태양 입력,
  ωc = ωs·Ns/(Ns+Nr))으로 이가 맞물려 회전 — 장식이 아니라 기계공학 그 자체.
- 마우스 시차 반응, 스크롤 시 속도·각도 변화. 코랄 발광 코어 + 은백색 기어 톤.
- 접근성·견고성: `prefers-reduced-motion` 시 정지 프레임, WebGL 미지원 브라우저는 SVG 폴백,
  화면 밖·백그라운드에서 렌더 정지, 첫 프레임 동기 렌더.

## 2. 관제(미션 컨트롤) 컨셉의 홈 히어로

- 네이비 우주 배경 + 코랄 궤도(3D 뒤로 배치) + 별 입자.
- 좌측 대형 학부명("기계공학부" 호버 시 블루 빔+글로우 효과).
- 우측 **"기계공학이 움직이는 것들"** 패널: 추상적 통계 대신 실물 응용 6종
  (휴머노이드·로봇 / 수소·배터리 / 반도체 장비 / 우주항공 구조 / 바이오칩 / 나노센서)
  → 각 연구 분야로 링크. 방문자가 첫 화면에서 "이 학부가 세상의 뭘 만드는지" 체감.
- 그 아래 **최근 소식 미니 피드**: 실데이터(공지·세미나) 상위 2건, 원문 링크.

## 3. 교수진 노출의 공평함 — 무작위 로테이션

- 홈 "학부를 움직이는 사람들" 카드 6개는 고정 인선이 아니라
  **방문(새로고침)마다 33명 전원 중 무작위 6명**을 렌더.
- 특정 교수를 "선정"하는 개념 자체를 제거 → 모든 교수님이 홈에 노출될 기회 동일.
- 각 카드는 교수 개인 프로필(디렉토리 행 앵커)로 딥링크. JS 미동작 시 정적 폴백.

## 4. 살아있는 상단 내비게이션

- 좌 연세대 공식 로고+학부명 / 중앙 메뉴(호버 드롭다운 — 항목마다 **실제 섹션 앵커**로 이동)
  / 우측 **현재 섹터 표시**: 홈에서는 스크롤에 따라 "학부 소개 → 연구 분야 → …"로 실시간 전환
  (IntersectionObserver 스파이), 내부 페이지에서는 페이지명.
- 공용 컴포넌트(`assets/nav.js`) 하나로 전 페이지 주입 — 유지보수 단일 지점.
- ≤920px 모바일: 햄버거 → 풀스크린 오버레이(포커스 관리·Esc·스크롤 잠금).

## 5. 스크롤 인터랙션

- 홈 콘텐츠 섹션 **양방향 리빌**: 내리면 아래에서 떠오르고, 올리면 위에서 내려오며 재등장
  (방향 감지 IntersectionObserver, 요소별 스태거, reduced-motion 제외, 미발화 안전망).
- 인스타그램 `@yonsei_mech` 릴스: 공식 임베드를 **한 줄 무한 마퀴**(좌측으로 55s/바퀴, 논스톱)로.

## 6. 데이터 단일 소스(SSOT) 구조

- 모든 목록 콘텐츠는 `assets/js/data.js`(window.YSME) 한 곳에서 렌더:
  교수 33 · 연구실 33(개별 홈페이지 31·소개영상 19·인턴 모집 12) · 학부 교과 40 ·
  대학원 교과 183 · 이수체계 49 · 공지(학부 26/대학원 22) · 뉴스 27 · 세미나 20 · 행사 10 ·
  취업 30 · 장학(교내 12/교외 19) · 연혁 · 연락처 메타.
- 데이터 한 곳만 고치면 홈 피드·디렉토리·연구·소식·입학 페이지가 동시 갱신.
- 연구 6분야는 학부 교수진 큐레이션(이메일 매핑) 기준: 역학·소재 / 에너지·열유체 /
  로보틱스·제어 / 설계·제조 / 마이크로·나노 / 바이오·포토닉스.

## 7. 찾아가는 정보 설계 (페르소나 UX 감사 기반)

고3 수험생·학부 재학생·대학원 준비생 3개 페르소나로 18개 과업 감사를 돌리고 전부 수리:
- **막다른 길 제거**: 입학처·대학원 모집요강 외부 링크, 가짜(하드코딩) 공지 → 실데이터 렌더,
  오시는 길·ABEEK 등 깨진 링크 수정.
- **교수진 디렉토리**: 분야·직위 칩 필터 + 통합 검색(이름·영문·연구실·호실·전화),
  사진·이름·연구실·연락처(✉ ☎ 아이콘 스택)가 줄 단위로 정렬된 3블록 레이아웃,
  URL 동기화(필터 상태 공유 가능), 개인 행 앵커(:target 하이라이트).
- **연구실 탐색**: 분야 분포 휠 → 분야 블록 → 연구실 행(연구주제 키워드 2줄·홈페이지·영상)
  + **학부연구생 모집 배지 12곳**(모집대상·혜택·주제 접이식) + 교수명 → 디렉토리 딥링크.
- **이수체계도**: 학년·학기 그리드의 과목을 클릭하면 해당 과목 상세 카드로 점프(하이라이트).
- **공지사항**: 학부/대학원 탭 × 카테고리 칩(수강·학사/장학/모집·채용/행사) × 제목 검색.
- **장학/취업 분리**: 학부·대학원 장학 구분, 취업 공고를 학생·졸업생/교원·연구원으로 분리.
- **고3 눈높이 용어 풀이**: 전필·전선·대교·시수 3(1)·모집요강·수시/정시 한 줄 설명.

## 8. 신뢰(사실만 게시) 원칙

- 없는 수치·통계는 만들지 않음(취업률 등은 "준비되는 대로 게시" 명시).
- 낡은 장학 데이터는 "게시 시점 기준" 캡션으로 안내.
- FAQ 전공필수 개수도 데이터 기준으로 정정(8→9과목).
- 공지·뉴스·세미나는 전부 학부 공식 홈페이지 원문으로 링크.

## 9. 운영 도구 — Admin Studio 연동

- 서버리스 관리자 콘솔(`admin/`): 브라우저에서 사이트 폴더를 직접 열어 비주얼 편집,
  버전 스냅샷·감사 기록, GitHub 게시(배포 저장소로 push → Vercel 자동 배포).
- 사이트 하단 흰 푸터의 작은 "관리자" 링크로 진입(일반 방문자 눈에 안 띔).

## 10. 접근성·성능 기본기

- 시맨틱 섹션·aria-labelledby·포커스 관리, 모든 모션에 `prefers-reduced-motion` 대응.
- 외부 링크 `rel="noopener"`+새 창 표시(↗), 이미지 lazy loading·이니셜 폴백.
- 프레임워크 0(바닐라)·빌드 0 — `git pull` 후 로컬 서버만으로 그대로 구동.
- 교수 사진 33장(240px 아바타, 총 332KB) + 학과장 원본 포트레이트.
