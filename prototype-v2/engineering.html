§90.4 인수

운영 · 인수 가이드

이 사이트를 인수받아 운영할 담당자를 위한 도면 주기(注記)입니다. 갱신은 대부분 data.js 한 파일 편집으로 끝납니다.

1. 파일 구조 SINGLE SOURCE OF TRUTH 
prototype-v2/
├── index.html                 # 홈 (§00) — 헤더·푸터 canonical 원본
├── about-dean.html · history.html · contact.html      # 소개 (§01)
├── research.html · lab.html · engineering.html         # 연구 (§02·§90)
├── people.html · professor.html                        # 구성원 (§03)
├── academics.html             # 교육 (§04)
├── news.html                  # 소식 (§05)
├── admissions.html            # 입학·진로 (§06)
├── privacy.html · terms.html · accessibility.html     # 정책 (§90)
├── TEMPLATE.md                # 서브페이지 제작 규약
└── assets/
    ├── css/main.css           # 디자인 토큰 + 전 컴포넌트 (단일 파일)
    └── js/
        ├── data.js            # ★ 모든 데이터의 단일 진실원천
        └── main.js            # 공용 UI (테마·드로어·검색·리빌·스탬프)

교수·연구실·공지 목록은 HTML에 복제되어 있지 않습니다. data.js만 고치면 홈 하이라이트·디렉터리·검색 인덱스가 함께 갱신됩니다.

2. 콘텐츠 갱신 절차 data.js EDIT
  • 교수 추가 — professors[]에 { id, ko, en, rank, cluster, labId, initial } 추가. id는 성-이름 로마자(예: kim-woochul), labId는 반드시 labs[]에 실재하는 id.
  • 연구실 추가 — labs[]에 { id, ko, en, pi, cluster, loc } 추가. cluster는 solid·thermal·manuf·nanobio·optics·dyn 6키 고정. 홈페이지 URL은 검증된 곳만 url 필드로.
  • 공지·뉴스·세미나 — posts[]에 추가. source(원본 게시판 경로)와 verifiedAt(확인일)은 필수 — 없으면 게시하지 않는 것이 이 사이트의 규칙입니다.
  • 수치 변경 — 화면의 모든 사실 수치에는 출처 스탬프(ⓘ)가 붙습니다. 수치를 바꾸면 스탬프의 출처·확인일도 반드시 함께 갱신하세요.
3. 배포 전 체크리스트 PRE-FLIGHT
  1. 서체 2종을 서브셋 woff2로 self-host 전환 (CDN 의존 제거 · OFL 1.1이므로 재배포 허용).
  2. Lighthouse 4개 카테고리 측정 → §90.1 실측 열과 홈 사양칩의 ‘측정 예정’을 실측값·측정일로 교체.
  3. 명도 대비 도구 검사(A-01)와 키보드 전수 감사(A-03) 수행 → §90.3 ‘검증 예정’ 6건 확정.
  4. OG 이미지·sitemap.xml·robots.txt 추가, 실서버 URL로 canonical 지정.
  5. 보안 헤더 권장값: CSP(self + 폰트 도메인), X-Content-Type-Options: nosniff, Referrer-Policy.
  6. 학교 UI/BI 가이드(엠블럼·연세블루)와 개인정보 표시 범위(교수 연락처 등) 최종 확인 — 담당 교수 사전 문의.
4. 인수 기준 — 품질 게이트 ACCEPTANCE

아래 8항을 모두 통과해야 인수 완료로 봅니다 (TEMPLATE.md §7과 동일).

  1. 다크(청사진) 모드 페이지 이동 시 흰 화면 깜빡임(FOUC) 없음.
  2. 페이지당 단일 h1 · 랜드마크 · skip 링크 · 인터랙티브 44px 이상.
  3. 필터·검색 결과 수를 aria-live로 안내, 빈 상태에 초기화 CTA.
  4. 자동재생 루프 0건 · reduced-motion에서 정적 완성형.
  5. 출처 스탬프 없는 사실 수치 0건.
  6. 가로 스크롤 0(테이블은 table-wrap 격리) · 한글 keep-all 유지.
  7. file://로 직접 열어 콘솔 에러 0.
  8. 보라 그라디언트 · 글래스모피즘 · 16px+ 라운드 · 임의 HEX 금지 준수.
