## Admin Studio 아키텍처 요약 (admin/ 수정 시 필독)

- 서버 없는 정적 SPA 입니다. File System Access API(Chrome/Edge)로 사이트 폴더를 직접 읽고 씁니다.
- 계정(PBKDF2-SHA256 15만회)·버전·감사 기록은 IndexedDB `ysme-admin`에 저장합니다.
- **핵심 원리**: "라이브 DOM은 화면, 원본(pristine) DOM이 진실"입니다.
  페이지를 열면 모든 요소에 `data-eid`를 부여해 iframe(srcdoc)에 렌더하고,
  편집은 eid로 원본 DOM에 미러링, 저장 시 eid를 제거한 원본을 파일에 씁니다.
  사이트 JS가 런타임에 넣는 상태(`.reveal.in`, `--reveal-delay`, i18n 텍스트,
  aria 토글)는 저장본에 새지 않도록 스크럽합니다 — 이 불변식을 깨면 안 됩니다.
- 보안: AI 초안·버전 미리보기는 `sandbox="allow-scripts"`(null origin) 프레임으로 렌더하고,
  콘솔 전체에 meta CSP 로 외부 유출을 차단합니다. API 키는 로그·버전·감사 기록에 절대 남기지 않습니다.
  단 **보드 프레임에는 sandbox 를 붙이지 않습니다** — 편집 캔버스와 같은 신뢰 수준(내 사이트 파일)
  이고, sandbox 를 붙이면 부모가 만든 blob: 자산을 못 읽어 빈 화면이 됩니다.
- 보드 모드(`board.js`): 모든 페이지를 실제 렌더된 iframe 프레임으로 무한 캔버스에 펼치고
  팬·줌으로 훑다가 더블클릭하면 그 페이지를 편집 모드로 엽니다. 15개를 동시에 렌더하면 브라우저가
  멈추므로 IntersectionObserver 로 화면 근처 프레임만 동시 2개까지 순차 렌더합니다.
- 모듈(로드 순서): core → store → auth → audit → fs → versions → editor → ai → board →
  github → app → layout. 전부 classic `<script defer>`, 전역 네임스페이스는 `Admin.*` 입니다.

## 인플레이스 스튜디오 사용법 (2축 핵심)

배포된 사이트를 방문자처럼 돌아다니면서 그 화면 위에서 고칩니다. 별도 콘솔을 열지 않습니다.

1. https://yonsei-me-homepage.vercel.app/H-academic.html**?studio=1** 로 접속합니다.
2. 공용 암호 + 편집자 이름을 입력하면 우하단에 버튼 7개가 뜹니다
   (편집 · 글등록 · 버전 · AI · 모바일 · 한·영 · 게시).
3. 「편집」을 켜고 글자를 클릭해 고칩니다. **초안은 브라우저에 쌓이고, 「게시」를 눌러야 파일에 반영됩니다**
   (여러 페이지·여러 파일이 GitHub 커밋 **1개**로 묶입니다).
4. 페이지를 옮겨도 편집 세션과 초안이 유지됩니다. 「편집」을 끄면 방문자와 완전히 동일하게 동작합니다.
5. 단축키: `E` 편집 토글 · `Ctrl+S` 초안 저장 · `Ctrl+Shift+P` 게시 · `Ctrl+Z/Y` 되돌리기 · `Esc` 선택 해제

- **세션이 없으면 스튜디오 파일을 요청조차 하지 않습니다** — 방문자 경험에 영향이 없습니다.
- 서버 함수 env(`GH_TOKEN`·`PUBLISH_PASSCODE` 등)는 Vercel 프로젝트 설정에만 있습니다. 저장소에 넣지 않습니다.

### AI 키 — 서버에 미리 등록해 두기 (시연용)

기본 동작은 「사람마다 자기 API 키를 브라우저에 등록」입니다. 시연 때는 그 단계가 거슬리므로,
**서버에 키를 심어 두면 공용 암호만 입력해도 곧바로 AI 수정이 열립니다.**

Vercel 프로젝트 → Settings → Environment Variables 에 넣습니다(저장소에는 절대 넣지 않습니다):

| 변수 | 값 | 비고 |
|---|---|---|
| `GEMINI_API_KEY` | aistudio.google.com 발급 키 | 무료 등급이면 요금 사고가 없습니다 |
| `ANTHROPIC_API_KEY` | (Claude 도 쓸 경우) | 없어도 됩니다 |
| `AI_RATE_MAX` | 기본 `100` | IP 당 창(window) 안에서 허용할 호출 수 |
| `AI_RATE_WINDOW_MS` | 기본 `300000` | 창 길이(밀리초) = 5분 |

기본값은 **IP 당 5분에 100회**입니다. 심사위원들이 같은 와이파이(= 같은 IP)에서 동시에 눌러 보셔도
넉넉하고, 암호가 새어 나갔을 때의 폭주는 여전히 막힙니다. 두 변수는 넣지 않아도 되며,
값을 바꿀 때는 **환경변수를 고친 뒤 재배포해야** 반영됩니다(코드와 같은 규칙입니다).

넣고 **재배포해야** 반영됩니다. 그 뒤의 동작은 다음과 같습니다.

- 로그인하면 스튜디오가 서버에 "키가 있는가"만 묻습니다(`{probe:true}`). **키 값은 브라우저로 내려오지 않습니다.**
- 키가 있으면 등록 화면을 건너뛰고 바로 요청 화면이 뜹니다. AI 패널에 「서버 키」 표시가 붙습니다.
- 개인 키를 등록해 둔 분은 **개인 키가 우선**합니다. 「키 변경 → 키 삭제」 하면 서버 키로 돌아옵니다.

> ⚠️ 이렇게 하면 **공용 암호가 API 요금을 지키는 유일한 방어선**이 됩니다
> (그 암호는 이미 `/api/publish` 로 저장소 커밋 권한도 쥐고 있습니다).
> 시연장에서 암호를 타이핑하는 화면이 보일 수 있으니 **시연이 끝나면 암호를 교체하십시오.**
> 호출 제한은 서버리스 인스턴스 메모리 기반이라 인스턴스가 여러 개면 그만큼 느슨해집니다 —
> 과금 사고를 막는 속도 방지턱이지 완전한 방어가 아닙니다.
- 화면의 카드·공지·교수 목록처럼 `assets/js/data.js` 가 그리는 영역은 HTML 이 아니라 **데이터 필드 편집**으로 안내됩니다.
- 영어 전환 중에 고친 글은 HTML 이 아니라 `assets/i18n/en.json` 사전에 들어갑니다.

### 새 공지·소식 등록 (「글등록」 버튼)

공지·뉴스·세미나·행사는 HTML 이 아니라 `assets/js/data.js` 의 배열이 원본이므로 화면 조작으로는
만들 수 없습니다. 「글등록」 패널이 그 배열 맨 앞에 항목 하나를 끼워 넣습니다.

1. 분류 선택 — 학부 공지 / 대학원 공지 / 연구 소식 / 세미나 / 행사 (노출 위치가 함께 표시됩니다)
2. 제목·날짜(기본 오늘)·링크·첨부 여부를 넣고 「등록」을 누릅니다. 입력칸은 기존 항목의 실제 필드에서
   자동으로 만들어지므로 데이터 모양이 바뀌어도 폼이 따라갑니다.
3. 등록한 글은 목록에 **미게시** 배지로 표시됩니다. 「게시」를 눌러야 사이트에 나갑니다.
   그 전까지는 같은 패널에서 삭제할 수 있습니다.

번호(`no`)를 `공지` 로 두면 목록 맨 위에 고정 표시됩니다. 세미나·행사는 다음 번호가 자동으로 채워집니다.

### 홈 한/영 사전 문장 (「홈 사전」 칩이 붙는 문장)

홈(`H-academic.html`)의 히어로·섹션 제목 등은 인라인 스크립트의 `var I18N = {ko:…, en:…}` 이
`textContent` 를 덮어씁니다. 이런 문장을 고를 때 인스펙터는 **한국어·English 두 칸**을 함께 보여 주고,
고치면 사전 값과 HTML 폴백 텍스트를 동시에 갱신합니다(`assets/studio/pagedict.js`).
예전처럼 "한/영 패널에서 고치세요" 로 막지 않습니다.

스크롤할 때 0부터 올라가는 숫자(`data-count`)는 「최종 숫자」 칸에서 목표값을 고칩니다.

## 사이트 인터랙션 (1축)

### 분야 아이콘 (`G-people.html` · `H-academic.html`)

여섯 개 연구 분야를 육각 글리프로 표시합니다. 한양대 기계공학부 학문분야 페이지의 정보 설계를
우리 데이터에 맞춰 옮긴 것입니다.

- 구성원 페이지: 사진 **왼쪽 레일**에 6칸을 둡니다. 그 교수의 분야만 색으로 채웁니다.
  채워진 칸이 섹션마다 아래로 내려가 "지금 어느 분야를 보는지"가 위치로 읽힙니다.
  활성 칸을 누르면 그 분야만 걸러 봅니다(비활성 칸은 `aria-hidden` 장식입니다 — 33장×6개를
  전부 탭 정지점으로 만들지 않습니다. 걸러 보기의 정식 경로는 위쪽 칩입니다).
- 홈: 카드가 작아 6칸 대신 **배지 1개**를 씁니다. 같은 글리프·같은 색입니다.
- 교수당 소속 분야는 데이터상 하나뿐입니다. 없는 교차 분야를 지어내지 않습니다.

### 몰입 구역 커서 (`assets/cursor.js`)

한화에어로스페이스 제품 소개 구역처럼 **일부 영역에서만** 커서가 바뀝니다.
즉시 따라오는 점 + 관성으로 늦게 따라오는 링, 두 겹 구조입니다.

```html
<div data-cursor-zone>                     <!-- 이 안에서만 커서가 바뀝니다 -->
  <a data-cursor="분야 보기"> … </a>        <!-- 링 안에 이 말이 뜹니다 -->
</div>
```

현재 구역: 홈 연구 분야 목록(`#areaGrid`), 연구 페이지 분야 카드(`#fieldGrid`).

지켜야 할 것:
- 기본 커서를 **전역으로 없애지 않습니다.** `cursor:none` 은 JS 가 성공했을 때만 붙는
  `html.ycur-live` 아래에서만 걸려, 스크립트가 죽어도 커서가 사라지지 않습니다.
- 터치·호버 불가·`prefers-reduced-motion`·폭 900px 미만이면 **아예 만들지 않습니다.**
- 편집 스튜디오가 편집 모드면 스스로 물러납니다(선택 상자와 싸우면 안 됩니다).
- 만드는 DOM 은 전부 `data-ys-ui` 입니다 — 편집 대상·번역 대상에서 빠집니다.
- 커서 라벨(`data-cursor`)은 속성 스캔 대상이 아니므로 `extract-i18n.js` 의 `EXTRA` 에 적어 둡니다.
