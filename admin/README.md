# YSME Admin Studio

연세대학교 기계공학부 사이트(prototype-v3) 관리자 편집 도구.
서버 설치 없이 브라우저에서 사이트 폴더를 직접 열어 편집하고, 변경 이력과 감사
기록을 이 기기에 보관한다.

## 개요

네 가지 기능을 제공한다.

- 비주얼 편집: 실제 페이지를 캔버스에 띄우고 요소를 클릭해 텍스트·스타일·속성을
  바로 수정한다. 요소 뒤에 자주 쓰는 블록(공지 행·기사 카드 등)을 바로 삽입할 수
  있고, 보드 모드로 사이트 전체 페이지를 한눈에 훑을 수 있으며, 코드 모드에서
  HTML 원문도 직접 편집할 수 있다.
- 찾기/바꾸기: 현재 페이지 또는 사이트 전체 페이지에서 텍스트를 한 번에 치환한다.
- 품질 검사: 현재 페이지의 접근성·내부 링크 문제를 저장과 무관하게 점검한다.
- AI 초안: Gemini에 수정 요청을 보내면 페이지 전체 수정본을 초안으로 받아
  미리보기 후 적용한다.
- 버전 롤백: 저장할 때마다 스냅샷이 쌓이며, 이전 버전을 미리보기·비교(디프)하고
  원하는 시점으로 복원한다.
- 계정·감사 기록: 로그인/저장/복원/AI 적용/내보내기 등 모든 조작이 기록으로 남고
  JSON으로 내보낼 수 있다.

## 요구 사항

- Chrome 또는 Edge(데스크톱). 폴더를 직접 읽고 쓰기 위해 File System Access
  API가 필요하다. Firefox·Safari와 모바일 브라우저는 지원하지 않는다.
- 편집 대상 사이트 폴더(예: `prototype-v3`).
- AI 초안 기능은 Google AI Studio에서 발급하는 무료 Gemini API 키.

## 시작하기

1. `admin/index.html`을 Chrome 또는 Edge로 연다.
   (폴더 선택 창이 열리지 않으면 아래 「문제 해결」의 `serve.py` 방법을 사용한다.)
2. 최초 실행이면 관리자 계정을 만든다. 아이디 3자 이상, 비밀번호 8자 이상.
   계정과 기록은 이 브라우저에만 저장된다.
3. 상단의 「사이트 폴더 열기」를 눌러 편집할 사이트 폴더를 선택한다.
4. `prototype-v3` 폴더를 고르고 접근을 허용한다. 좌측에 페이지 목록이 나타나면
   준비 완료다.

## 온라인 편집 (인터넷에서 접속)

로컬 폴더를 열지 않고, 인터넷 어디서든 **공용 암호 하나로** 사이트를 편집·배포하는
모드다. 파일을 로컬 폴더 대신 서버 함수(`prototype-v3/api/publish.js`)를 통해 GitHub
에서 직접 읽고 쓴다. 보드·비주얼 편집·찾기바꾸기·품질 검사 기능을 그대로 쓴다.

- **주소**: 배포 사이트의 `/studio` (예: `https://prototype-v3-nine.vercel.app/studio`).
- **접속**: 공용 암호 + 편집자 이름만 입력한다(계정 로그인 없음). 저장(Ctrl+S)하면
  GitHub에 커밋되어 배포된 사이트에 바로 반영된다.
- **보안**: 공용 암호 하나가 곧 사이트 쓰기 권한이다. 강한 암호를 쓰고, 저장마다 남는
  버전 스냅샷·GitHub 이력·Vercel 롤백으로 되돌린다. 자세한 한계는 「보안 한계 고지」.
- **동작 원리**: 호스팅된 `studio/index.html` 이 `window.YSME_ONLINE` 플래그를 켜면
  `remotefs.js` 가 로컬 File System 대신 서버 함수를 쓰도록 `Admin.fs` 를 교체하고,
  `online.js` 가 계정 게이트 대신 공용 암호 게이트를 띄운다. 플래그가 없는 로컬 모드는
  전혀 영향받지 않는다.

### 온라인 스튜디오 배포·갱신

1. 서버 함수 env가 설정돼 있어야 한다(아래 「공동 게시」와 동일: `GH_TOKEN`, `GH_OWNER`,
   `GH_REPO`, `GH_BASEPATH=prototype-v3`, `PUBLISH_PASSCODE`).
2. `python admin/deploy-studio.py` 실행 → `admin/` 을 `prototype-v3/studio/` 로 복사하고
   온라인 플래그를 주입한다. (`studio/` 는 **생성물**이니 직접 고치지 말고, `admin/` 을
   고친 뒤 이 스크립트를 다시 돌려 동기화한다.)
3. `prototype-v3/` 를 커밋·푸시하면 자동 배포되어 `/studio` 가 열린다.

> 로컬에서 게이트를 미리 보려면 `?online=1` 을 붙인다:
> `http://localhost:8787/admin/index.html?online=1` (성공 접속은 배포된 함수가 필요).

## 기능 사용법

### 비주얼 편집

- 좌측 「페이지」 탭에서 편집할 HTML을 선택하면 캔버스에 렌더된다. 페이지가 많으면
  목록 위 검색창에 파일명이나 한국어 이름 일부를 입력해 걸러낸다.
- 상단 모드바에서 편집 / 미리보기 / 보드 / 코드를 전환한다. 데스크톱·모바일 뷰포트도
  여기서 바꾼다.
- 편집 모드에서 요소를 클릭하면 우측 「요소 편집」 패널에 해당 요소의 텍스트·
  속성·스타일 필드가 표시된다. 값을 바꾸면 캔버스에 즉시 반영된다.
- 캔버스에서 요소 위에 마우스를 올리면 그 요소의 태그 이름표(`section.hero` 등)가
  뜬다. 파랑은 가리키는 중, 골드는 선택된 요소다.
- 우측 패널 맨 위의 요소 경로는 버튼이다. 상위 요소를 눌러 바깥 요소를 선택할 수
  있다(예: 문단 → 감싸는 섹션). 버튼 위에 마우스를 올리면 캔버스에서 그 위치를
  미리 비춰 준다.
- 스타일 필드의 「글자 크기 (px)」는 −/＋ 버튼이나 직접 입력으로 조절한다.
  비워 두거나 「기본」을 누르면 인라인 크기를 지우고 원래 CSS 크기로 돌아간다.
  입력란의 흐린 숫자는 현재 계산된 크기다.
- 「굵기」는 보통(400)부터 아주 굵게(800)까지 선택 상자에서 고른다.
  「행간 (배수)」는 글자 크기의 배수(0.9~3.0)로, −/＋ 버튼(0.05 단위)이나 직접
  입력으로 조절한다. 비워 두거나 「기본」을 누르면 원래 행간으로 돌아가며,
  입력란의 흐린 숫자는 현재 계산된 배수다.
- 이미지를 클릭하면 속성 섹션에 「이미지 교체…」 버튼이 나타난다. 파일을
  고르면 사이트의 `assets/img/` 폴더에 즉시 저장되고(같은 이름이 있으면 -2,
  -3 번호가 붙는다) 캔버스에 바로 반영된다. 단, 페이지(HTML)의 `src` 변경은
  「저장」(Ctrl+S)을 눌러야 파일에 기록된다. 접근성을 위해 대체 텍스트(alt)도
  함께 입력한다.
- 요소를 선택하면 우측 「동작」 섹션에 「블록 삽입」 선택 상자가 나타난다. 원하는
  블록(공지 행 · 기사 카드 · 제목+단락 섹션 · 구분 헤어라인 · 버튼 2개 행)을 고르고
  「삽입」을 누르면 선택 요소 바로 뒤에 자리표시 마크업이 추가되고 새 블록이 자동으로
  선택된다. 이어서 텍스트·링크를 채워 넣으면 된다. (요소를 고르지 않으면 안내 메시지가
  뜬다.)
- 선택한 요소는 키보드로도 다룬다. Del 삭제, Ctrl+D 복제, Alt+↑/↓ 순서 이동,
  Esc 선택 해제. 글자를 입력하는 중에는 이 키들이 발동하지 않는다.
- 코드 모드에서는 파일 원문(HTML/CSS/JS)을 직접 편집한다. 편집할 파일은 코드
  영역 상단 선택 상자에서 고른다.
- 실행 취소(Ctrl+Z)·다시 실행(Ctrl+Y)을 지원한다.
- 상단 「저장」(Ctrl+S)을 누르면 변경 내용이 실제 파일에 기록되고 버전 스냅샷이
  한 개 생성된다. 저장 전에는 파일이 바뀌지 않는다.

### 보드 모드

사이트의 모든 페이지를 실제 모습 그대로 한 화면에 펼쳐 놓고 훑어보는 지도다.
어느 페이지를 고칠지 찾을 때, 또는 전체 톤이 고르게 맞는지 볼 때 쓴다.

- 모드바의 「보드」(단축키 3)를 누르면 열린 사이트의 모든 페이지가 프레임으로
  배치된다. 각 프레임은 축소된 그림이 아니라 실제로 렌더된 페이지다.
- 화면 이동은 빈 배경을 드래그한다. 프레임 위에서 이동하려면 스페이스바를 누른
  채 드래그하거나 마우스 가운데 버튼으로 드래그한다.
- 확대·축소는 Ctrl+휠(또는 트랙패드 핀치)이다. 휠만 굴리면 세로로, Shift+휠은
  가로로 움직인다. 툴바의 −/＋ 버튼도 같은 역할을 한다.
- 「전체 맞춤」은 보이는 프레임 전부가 들어오도록 맞춘다. 가운데 배율 표시(예:
  100%)를 누르면 100%로 돌아오면서 현재 편집 중인 페이지를 화면 중앙에 놓는다.
- 프레임을 한 번 클릭하면 선택되고(골드 테두리), **더블클릭하면 그 페이지가 편집
  모드로 열린다.** 프레임 위쪽의 이름표를 클릭해도 열린다. 키보드로는 Tab으로
  프레임에 이동한 뒤 Enter를 누른다.
- 현재 편집 중인 페이지는 이름이 파란색이고 테두리가 강조된다. 저장하지 않은
  변경이 있으면 이름표 옆에 「미저장」이 붙고, 그 미저장 내용이 보드에도 그대로
  보인다.
- 툴바의 검색창에 입력하면 해당 페이지만 남기고 다시 배치한다(남은 프레임에 맞춰
  배율도 다시 잡힌다). 일치하는 페이지가 없으면 그 사실을 화면에 알려 준다.
- 「모바일 폭」을 켜면 모든 프레임을 390px 폭으로 다시 그린다. 모바일 레이아웃을
  한눈에 비교할 때 쓴다.
- 기본은 **커버 보기**다. 페이지마다 첫 화면 분량(900px)만 같은 높이로 잘라 보여
  준다. 페이지 실제 길이는 서로 10배씩 차이 나서, 전체 길이를 그대로 늘어놓으면
  「전체 맞춤」 배율이 4%까지 내려가 아무것도 알아볼 수 없기 때문이다. 높이를
  맞추면 페이지끼리 비교가 되고 이름표도 읽힌다. 아래가 더 있다는 뜻으로 프레임
  하단이 살짝 흐려진다.
- 페이지 전체 길이를 보려면 「전체 높이」를 켠다. 이때는 화면이 많이 축소되고,
  아주 긴 페이지는 끝이 잘리며 「잘림」 표시가 붙는다.
- 파일을 저장하면 해당 프레임이 자동으로 다시 그려진다. CSS·JS를 저장한 경우에는
  모든 프레임이 새로 그려진다.
- 보드는 보기 전용이다. 프레임 안을 직접 클릭해 내용을 고칠 수는 없다.

### 찾기/바꾸기

- 상단 「찾기/바꾸기」 버튼을 누르면 모달이 열린다.
- 「찾을 내용」과 「바꿀 내용」을 입력하고, 필요하면 「대소문자 구분」을 켠다.
  치환은 HTML 원문 기준의 평문(plain-text) 전체 치환이다.
- 범위는 「현재 페이지만」 또는 「모든 페이지」에서 고른다.
- 「미리보기」를 누르면 파일별 일치 개수와 문맥 스니펫(일치 부분 강조)을 먼저 확인할
  수 있다.
- 「모두 바꾸기」를 누르면 실제 파일에 반영된다. 바뀌는 각 파일은 쓰기 전에 버전
  스냅샷이 자동으로 남아 「버전」 탭에서 되돌릴 수 있으며, 감사 기록에도 남는다.
- 현재 페이지에 저장하지 않은 변경이 있거나 코드 모드일 때는 실행이 막힌다. 먼저
  저장하거나 편집 모드로 전환한 뒤 실행한다.

### 품질 검사

- 상단 「품질 검사」 버튼을 누르면 현재 편집 중인 페이지를 점검한 결과가 모달로
  나타난다. 저장에는 영향을 주지 않는 비차단 검사다.
- 다음 항목을 심각도별(오류/주의)로 묶어 보여 주며, 항목마다 문제 요소의 경로를
  함께 표시한다.
  - 오류: 이미지에 대체 텍스트(alt)가 없음 / 내부 링크가 깨짐(사이트에 없는
    `*.html`이거나 문서에 없는 `#앵커`).
  - 주의: h1이 정확히 1개가 아님 / 제목 레벨을 건너뜀(예: h2 다음 h4) /
    링크·버튼에 읽을 수 있는 텍스트나 aria-label이 없음.
- 문제가 하나도 없으면 「통과」로 표시된다.

### AI 초안

- 우측 「AI 어시스턴트」 탭을 연다.
- API 키 발급: 브라우저에서 `aistudio.google.com`에 접속해 로그인한 뒤
  「Get API key」에서 키를 생성하고 `AIza...`로 시작하는 문자열을 복사한다.
- 도구에 키를 붙여넣고 모델을 선택한 뒤 「연결」을 누른다. 키는 이 브라우저에만
  저장되며 기록이나 버전에는 남지 않는다.
- 입력창에 수정 요청을 한국어로 설명하고 전송한다. AI는 변경 요약과 함께
  페이지 전체 수정본을 초안으로 만든다.
- 초안이 준비되면 「미리보기」로 캔버스에서 확인하고, 「적용」으로 편집 내용에
  반영하거나 「버리기」로 취소한다. 적용해도 「저장」 전에는 파일이 바뀌지 않는다.
- 추가 메시지를 보내면 대화 맥락을 유지한 채 초안을 다시 다듬는다.
- 특정 요소를 선택한 상태에서 요청하면 그 요소에 집중한 수정본을 받는다.
- 키·모델은 「API 키 · 모델 변경」에서 다시 설정한다.

### 버전 롤백

- 좌측 「버전」 탭에서 저장 이력을 최신순으로 확인한다. 상단 선택 상자로 파일별
  필터링한다. 파일을 처음 열면 원본이 기준(baseline) 스냅샷으로 자동 저장된다.
- 각 버전 행의 버튼:
  - 미리보기: 해당 버전을 캔버스에 읽기 전용으로 띄운다.
  - 비교: 현재 편집 내용과의 라인 디프를 모달로 보여 준다(추가·삭제 표시).
  - 복원: 확인 후 그 버전 내용으로 파일을 되돌리고 복원 스냅샷을 남긴다.

### 계정·감사 기록

- 좌측 「기록」 탭에서 로그인·계정 생성·저장·복원·AI 적용·내보내기·사이트 열기
  기록을 최신순으로 확인한다.
- 「감사 기록 내보내기 (JSON)」로 전체 기록을 파일로 내려받는다.
- 우상단에서 로그아웃하며, 세션은 브라우저를 닫으면 만료된다.

## 단축키

모드바 오른쪽의 「?」 버튼을 누르거나 `?` 키를 치면 같은 내용을 도구 안에서 볼 수 있다.
입력창이나 캔버스에서 글자를 입력하는 중에는 조합키가 아닌 단축키(1~4, ?)가 발동하지
않는다.

| 키 | 동작 |
|---|---|
| `1` / `2` / `3` / `4` | 편집 / 미리보기 / 보드 / 코드 모드 |
| `Ctrl+S` | 저장 |
| `Ctrl+Z` / `Ctrl+Y` | 실행 취소 / 다시 실행 |
| `Esc` | 선택 해제 |
| `Del` | 선택 요소 삭제 |
| `Ctrl+D` | 선택 요소 복제 |
| `Alt+↑` / `Alt+↓` | 선택 요소 순서 이동 |
| `?` | 단축키 도움말 |

보드 모드 전용:

| 조작 | 동작 |
|---|---|
| 드래그 | 화면 이동 (빈 배경) |
| `Space`+드래그 | 화면 이동 (프레임 위에서도) |
| `Ctrl`+휠 | 확대 · 축소 |
| 휠 / `Shift`+휠 | 세로 이동 / 가로 이동 |
| 더블클릭 | 그 페이지를 편집 모드로 열기 |

모드 전환(1~4)은 사이트 폴더를 연 뒤에만 동작한다.

## 보안 한계 고지

이 도구는 서버 없이 동작하는 정적 데모다. 다음을 전제로 사용한다.

- 관리자 계정·비밀번호 해시·버전·감사 기록은 모두 이 브라우저의 로컬 저장소
  (IndexedDB)에 보관된다. 다른 기기·브라우저와 공유되지 않으며, 브라우저 데이터를
  지우면 함께 사라진다.
- 로컬 인증이므로 여러 관리자·권한 분리·원격 접근 통제 같은 실서비스 수준의
  보안은 제공하지 않는다.
- Gemini API 키도 브라우저에만 저장된다. 공용 PC에서는 사용 후 키를 삭제한다.
- AI 초안·버전 미리보기는 격리된(sandbox) 프레임에서 렌더되어 도구의 저장소
  (API 키·계정 정보)에 접근할 수 없고, 콘솔 전체에 CSP를 적용해 허용된 호스트
  (폰트 CDN·Gemini API) 외부로의 네트워크 전송을 차단한다.
- 실제 운영 환경으로 전환하려면 인증·데이터·감사 기록을 처리하는 별도 서버가
  필요하다.

## 문제 해결

- 폴더 접근이 막히거나 재접속 시 권한이 필요하면, 「사이트 폴더 열기」를 다시
  눌러 폴더를 재선택하고 접근을 허용한다.
- `file://`로 열었을 때 폴더 선택 창이 열리지 않으면 로컬 서버로 실행한다.
  터미널에서 `python admin/serve.py`를 실행하면 `http://localhost:8787`로 서빙하고
  콘솔을 자동으로 연다. 종료는 Ctrl+C.
- AI 응답에 HTTP 400 또는 403이 표시되면 API 키가 올바른지, 키가 활성 상태인지
  확인한다.
- AI 응답에 HTTP 429가 표시되면 Gemini 무료 쿼터를 초과한 것이다. 잠시 후
  다시 시도하거나 더 가벼운 모델을 선택한다.
