# 「機制 · Mechanism in Motion」 — 디자인 시스템 & UX 설계서 (v1.0 / 실행본)

> 연세대 기계공학부 홈페이지 경진대회 · 디자인·UX 30점 공략 전용 설계서

> 원칙: **모든 토큰·컴포넌트는 "작동하는 공학 도면"이라는 단일 시각 DNA(치수선·모눈·모노스페이스)에서 파생**된다. 장식이 아니라 점수다.

## 0. 이 문서의 사용법 — 컨셉을 픽셀로 번역하는 5개 규칙

| 컨셉 원소 | 디자인 시스템에서의 구현체 | 적용 컴포넌트 |
|---|---|---|
| **치수선(dimension line)** | `border-hair` 1px + 끝단 틱(│─┤) + 모노 수치 라벨 | 섹션 구분선·카드 콜아웃·여백 주석·통계 밴드 |
| **모눈(engineering grid)** | 12-col 그리드 + `--ink-grid` 8px 서브그리드 배경 | 전 페이지 레이아웃·히어로 배경 |
| **계측(measured)** | IBM Plex Mono 전용 영역(코드·전화·치수·좌표·수치) | 교수/랩 메타·통계·사양칩·스탬프 |
| **출처 스탬프(datum)** | `<SourceStamp>` 인라인 틱 → 호버 시 `출처·최종확인일` 패널 | 모든 사실 수치·교수 데이터 |
| **정중동(靜中動)** | 유휴=정지 도면 / 의도(스크롤·호버)에만 발동 / 자동재생 0 | 전 모션 |

**핵심 규율 한 줄:** 화면 어디든 *움직이면 기계공학 개념을 가리키고(referent), 멈추면 출처가 남는다.* 이 두 제약을 통과 못 하는 모션·수치는 빌드에서 삭제.

**컬러 사용 규칙(준법·일관성 트리거):**
- 연세 블루는 변형·그라디언트 금지 → `--blue-900` 단색만 브랜드 면적에 사용(UI/BI 가이드 준수).
- 금색은 **면적 ≤5%**, 본문 텍스트 절대 금지. 위반 시 "학생 포폴" 정서.
- 보라 그라디언트·네온·글래스모피즘 HEX는 팔레트에 **존재하지 않음**(AI 슬롭 구조적 차단, §8).
- 6 클러스터 색은 항상 `solid(점/아이콘) + ink(텍스트) + bg(칩배경)` 3종 세트로만 사용 → 어디서든 동일 매핑(일관성).

### 1.2 타이포그래피 — "이 학부는 측정한다"는 타이포 서명

**2-폰트 시스템(라이선스 안전):** Pretendard(OFL, 한/영 본문) + IBM Plex Mono(OFL/Apache, **코드·전화·치수·좌표·수치 전용**). 서브셋 self-host.

```css
/* 한글 조판 필수 — 경쟁작이 놓치는 디테일 */
```

### 1.3 스페이싱 — 8px 베이스(4px 하프스텝)

`0·1px·2·4·8·12·16·20·24·32·40·48·64·80·96·128` → `--space-{n}`. 컴포넌트 내부=4/8/12/16, 컴포넌트 간=24/32, 섹션 간=`clamp(64,8vw,128)`.
- 본문 측정폭(measure): **max 72ch (≈680px)** — 한글 가독 상한.
- 터치 타깃 최소 **44×44px**(간격 ≥8px).

## 2. 그리드 & 레이아웃 시스템 — "엔지니어링 모눈"

- **12-col 그리드**, gutter `24px`(md+) / `16px`(mobile), 마진 `clamp(16,5vw,80px)`.
- **컨테이너:** `--container: 1280px`(콘텐츠) / `--container-wide: 1440px`(히어로·그래프) / `--measure: 680px`(읽기 본문).
- **치수선 거터:** 섹션 좌측에 세로 치수선 + 모노 섹션번호(`§02 연구`)를 반복 모티프로 → 8개 콘텐츠 영역 전부 동일 적용(=눈에 보이는 디자인 시스템 = 일관성 만점 트리거).
- **모눈 배경:** `background: repeating-linear-gradient(...) var(--ink-grid)` 8px 서브그리드를 히어로·구분 섹션에 **2% 불투명도**로 깔아 "제도지" 질감(성능 0 비용, pure CSS).
- **섹션 리듬:** 세로 패딩 `clamp(64,8vw,128)`. 교차 배경 `paper-0 ↔ paper-50`로 스캔 가능성 확보.
- **콜아웃 정렬:** 도판·통계는 그리드 라인에 스냅 + 치수선으로 폭 주석(`├─ 680 ─┤`).

## 3. 핵심 컴포넌트 라이브러리

> 각 컴포넌트: **용도 / 해부 / 상태 / 반응형 / a11y / 컨셉 훅**. 모든 카드는 공통 셸 `Card`(border-hair + radius-sm + shadow-1, hover→shadow-2)를 상속해 일관성 확보.

### 3.1 헤더 & 글로벌 내비게이션
- **IA(행정축→문제·사람·배움축 재편):** `소개 · 교육 · 연구 · 구성원 · 소식 · 입학·진로` 6개 + 유틸(**통합검색 / KO·EN / 다크모드**).
- **해부:** 좌=연세 엠블럼+「연세대 기계공학부」 워드마크(blue-900) / 중=6 메뉴 / 우=검색(돋보기)·언어토글·테마.
- **단일 DOM 반응형(★안티패턴 차단):** 데스크톱/모바일 메뉴를 **한 벌**로 작성, CSS로 분기(연세·KAIST의 DOM 이중생성 안티패턴 제거 → 기술·접근성·유지보수 동시 득점).
- **메가메뉴(lg+):** 메뉴 호버/포커스 시 하단 패널 전개 — 각 패널에 **치수선으로 구분된 하위링크 + 우측에 해당 영역 datum**(예: 연구 패널 우측 `연구실 33 · 클러스터 6`). `dur-base`/`ease-standard`.
- **스크롤 거동:** 80px→56px 컴팩트(하어라인 보더 출현), `position: sticky`, 그림자 없이 보더로 분리.

## 0) 한 줄 아키텍처 + 5대 기술 원칙

**Astro 5 (static-first, islands) + TypeScript strict + Content Layer(YAML/MDX, Zod 검증) + Keystatic(Git CMS) + Pagefind(정적검색) + Vercel(+정적 export 이양) + GitHub Actions 품질게이트.**

1. **정적이 디폴트, JS는 섬(island)만** — 콘텐츠 페이지는 JS 0KB. 모션·그래프만 선택 하이드레이션 → 모바일 Lighthouse 구조적 우위(경쟁작 Next-SPA가 50~70으로 무너지는 지점). 컨셉의 *정중동(靜中動)* = Astro의 zero-JS + `client:visible` 1:1 대응.
2. **단일 진실원천(`src/data/`)** — 교수33·연구실33·교과목·공지가 전부 타입드 콘텐츠. 손수 HTML 0건. CMS도 이 폴더에 커밋.
3. **빌드가 사양·정확성·접근성을 강제** — Zod 스키마 위반·깨진 링크·Lighthouse 미달·axe 위반 시 **배포 차단**. "엔지니어가 졸업해도 빌드가 지킨다"(가설C·ops 이식).
4. **벤더 락인 0** — `output: 'static'` → 학교 정보화팀이 어떤 호스팅(nginx/Cloudflare/GitHub Pages)에도 재탑재. 이게 곧 이양 점수.
5. **자기계측 정직성** — 성능·접근성 수치는 CI 실측 JSON + 커밋해시·측정시각으로 `/공학`이 자가 게시. 하드코딩 희망수치 0.

## 2) 렌더링 전략 — SSG 전면, ISR 불요(이유 포함)

- **전 페이지 SSG**(`output: 'static'`). 근거: 콘텐츠 소스가 **Git**이라 모든 변경 = 커밋 = 자동 리빌드. 외부 동적 소스가 없으므로 ISR(시간기반 재생성)의 존재 이유가 없다. 또 SSG라야 **정적 export 이양·"500 구조적 불가"** 가 성립.
- **빌드 트리거:** Git push(콘텐츠/코드) → Vercel 빌드. 콘텐츠 변경은 Astro 5 Content Layer 캐시 + Vercel 빌드캐시로 증분 처리 → 리빌드 단축.
- **ISR/Server Islands는 에스케이프 해치로만 문서화:** "지금 대학원생 모집중인 연구실" 같은 *진짜 실시간* 플래그가 후일 필요해지면 그 컴포넌트만 Server Island(또는 Astro hybrid + on-demand revalidate)로. 코어는 SSG 유지. → 발표 Q&A "동적 필요하면?"에 대한 정답.

〈심사 직결〉 안정성 — 서버 런타임 0 = 런타임 크래시·500 불가. Git 이력 = 즉시 롤백.

**콘텐츠 모델 = 구조데이터(YAML) + 편집물(MDX), 전부 Content Collection으로 타입드.** Zod 스키마가 이 컨셉의 핵심 거버넌스(출처스탬프·정확성·placeholder 0)를 **빌드에서 강제**:

```ts
// src/content.config.ts
import { defineCollection, z, reference } from 'astro:content';
import { glob } from 'astro/loaders';

const provenance = z.object({                          // ★모든 사실에 출처+최종확인일
  source: z.string().min(1),                            // 예: "faculty_list.do"
  verifiedAt: z.string().regex(/^\d{4}-\d{2}-\d{2}$/),  // 누락 시 빌드 실패
});

const professors = defineCollection({
  loader: glob({ pattern: '**/*.yaml', base: './src/data/professors' }),
  schema: ({ image }) => z.object({
    nameKo: z.string(), nameEn: z.string(),
    titleKo: z.enum(['교수','부교수','조교수']), titleEn: z.string(),
    email: z.string().email(),                          // 파싱오류·오타 빌드차단
    phone: z.string().regex(/^02-2123-\d{4}$/).optional(),
    labId: reference('labs'),                           // 깨진 교차링크 빌드차단
    clusters: z.array(z.enum([                          // 6클러스터 = 전역 필터 키
      '고체·구조·재료역학','열·유체·에너지','생산·정밀제조',
      '마이크로·나노·바이오시스템','광학·이미징·계측','동역학·제어·로보틱스·AI',
    ])).min(1),
    photo: image().optional(),
    photoConsent: z.boolean().default(false),           // 동의 없으면 사진 미렌더
    _provenance: provenance,
  }),
});
export const collections = { professors, labs, posts, courses };
```

이 스키마 하나가: ①이메일/전화 형식 오류·깨진 lab 참조 = **빌드 실패** ②출처스탬프 누락 = **빌드 실패**(evidence 거버넌스 자동화) ③동의 없는 사진 = 미렌더(개인정보) ④`clusters`가 교수·연구실·교과목·뉴스 4-way 교차링크와 검색필터의 공통 키. **placeholder 0건 원칙이 "정신"이 아니라 "컴파일러"가 된다.**

〈심사 직결〉 콘텐츠·정보구조 20 — 33×33 실데이터 + 출처스탬프 + 교차링크를 타입시스템이 보증.

## 4) ★ 콘텐츠옵스 — 교수/조교가 코드 없이 (편집 → 미리보기 → 배포)

핵심 채택 레버. **Keystatic(Git 기반 헤드리스 CMS, 무료)** 를 Astro에 네이티브 통합 → 콘텐츠 스키마와 CMS 스키마가 **단일 정의**(드리프트 0). 비개발자가 `/keystatic`(운영 시 `/admin`) WYSIWYG로 편집 → GitHub 커밋 → Vercel 빌드.

```ts
// keystatic.config.ts  (Astro content collection과 1:1)
import { config, collection, fields } from '@keystatic/core';
export default config({
  storage: { kind: 'github', repo: 'todo0157/yonsei-me' },  // GitHub OAuth = 권한제어
  ui: { brand: { name: '연세 ME 운영 콘솔' } },
  collections: {
    posts: collection({
      label: '공지·뉴스', slugField: 'title', path: 'src/data/posts/*',
      format: { contentField: 'body' },
      schema: {
        title: fields.slug({ name: { label: '제목' } }),
```

1. **로그인:** `me.yonsei.ac.kr/admin` → 학교 GitHub 계정으로 OAuth(최초 1회 초대).

## 5) 성능예산 — LCP/CLS/INP 목표 + Lighthouse 100 달성법

### 예산표 (게이트로 강제, 위반 시 배포 차단)
| 지표 | 목표 | 게이트 상한 | 측정/달성 |
|---|---|---|---|
| LCP (모바일 랩) | < 1.0s | **≤ 1.2s** | 히어로=인라인 SVG+서브셋폰트 preload, 렌더블로킹 0 |
| CLS | < 0.01 | **≤ 0.02** | 전 이미지 width/height·aspect-ratio, 폰트 `size-adjust` |
| INP / TBT | < 100 / 150ms | **TBT ≤ 150ms** | 콘텐츠 JS 0KB, 그래프만 rAF·debounce |
| 홈 JS(압축) | ~0KB | **≤ 50KB** | island 없음(히어로는 CSS), 분석스크립트만 async |
| 그래프 라우트 JS | — | **≤ 120KB(lazy)** | force-graph는 `client:visible`로 해당 라우트만 |
| 페이지 총 전송량 | < 400KB | **≤ 600KB** | lhci `total-byte-weight` 경고 |
| 폰트/페이지 | < 120KB | — | Pretendard 한글 subset + Plex Mono(라틴·숫자만) |

> **정직성:** 모바일 랩(느린4G·4×CPU)에서 4×100은 야심적이라 **게이트는 회귀방지선(perf ≥ 0.95, a11y = 1.0, LCP ≤ 1.2s)** 으로 잡고, `/공학`은 **그날 빌드의 실측값을 커밋해시와 함께** 게시. 하드코딩 100 금지(자기참조 페이지 날조 = 자멸).

### 이미지/폰트 (한국어 특화)
- **이미지:** `astro:assets`의 `<Image>`로 AVIF→WebP fallback, 반응형 `srcset`, 교수사진=표시치수(예 400×400, 2x retina)로 사전 리사이즈, below-fold `loading="lazy"`, LCP 이미지(있으면) `fetchpriority="high"`. solid-color LQIP로 CLS 0.
- **폰트:** **Pretendard**(OFL) 한글 subset을 `unicode-range`로 분할, woff2, above-fold 1웨이트만 `preload`. **IBM Plex Mono**(과목코드·치수·전화)는 라틴+숫자만 subset(~15KB). `font-display: swap` + `size-adjust`/`ascent-override`로 폰트교체 레이아웃시프트 제거. **self-host(외부 CDN 0)** → Best Practices·개인정보 동시 충족.

### Lighthouse 100 4분면 달성 체크
- **Performance:** static HTML, 렌더블로킹 0(크리티컬 CSS 인라인, 나머지 defer), 폰트 preload, 3rd-party 0(분석은 async·경량).
- **Accessibility:** §6(대비·alt·라벨·랜드마크) → 100.
- **Best Practices:** HTTPS, 콘솔에러 0, CSP/보안헤더, deprecated API 0.
- **SEO:** 메타·canonical·**hreflang**·sitemap·robots·시맨틱.

### 시그니처 모먼트의 성능 안전장치
- **히어로 슬라이더-크랭크:** pure SVG + CSS `stroke-dashoffset`(<15KB, 무라이브러리). 스크롤연동은 `animation-timeline: scroll()`(Chrome/Edge) → 미지원(Safari/FF 일부)·`prefers-reduced-motion`은 **IntersectionObserver+rAF 폴백 또는 완성 정적도면**. Three.js 미사용 → LCP 보호.
- **지식그래프:** canvas 기반 force-graph(DOM 노드 아님), `client:visible` lazy(해당 라우트만), 데이터=빌드시 생성 정적 JSON. 폴백=클러스터 아코디언/탭 리스트(SR·모바일·reduced-motion 공용).
- **`/공학`:** CI 산출 JSON import + 빌드시 `git rev-parse HEAD`·시각 주입(정적, 무비용).
- **3D(P2):** `<model-viewer>` GLB(자작 CAD만) 1개 랩, poster 폴백, 예산 게이트 내에서만.

〈심사 직결〉 기능·기술 30(성능·반응형) — 빌드 게이트 + RUM으로 "주장"이 아닌 "증거".

## 6) 접근성 — WCAG 2.1 AA + KWCAG 2.2 (구체 구현 + 검증)

공공 대학 = 장애인차별금지법·웹접근성 대상 → 단순 가점이 아니라 **채택 리스크 회피**. 손실회피적 교수위원회의 결격-스크린을 정면 통과.

- **시맨틱·랜드마크:** `header/nav/main/aside/footer`, 페이지당 단일 `h1`, 논리적 heading 순서, 목록·표는 `caption`/`th scope`.
- **Skip links:** "본문 바로가기"·"내비 바로가기"(ETH 벤치마크 패턴).
- **키보드:** 전 인터랙티브 요소 포커서블, `:focus-visible` 2px 링(배경 대비 AA), 논리적 탭순서, 트랩 0.
- **ARIA(시맨틱으로 부족할 때만):** 검색=`role=combobox/listbox`+`aria-activedescendant`; 그래프 SVG=`role=img`+`aria-label`+오프스크린 노드/엣지 텍스트 대안; 언어토글=`aria-current`; 치수선 장식 SVG=`aria-hidden`.
- **대비:** 연세블루/화이트 본문 ≥ 4.5:1. **금색은 대형텍스트(≥24px 또는 18.66px bold)·비텍스트 노드 전용**(≥3:1) — 컨셉의 금색 제한이 곧 AA-safe 토큰규칙. 토큰에 명문화해 위반 차단.
- **모션:** `prefers-reduced-motion` → 전 모션 정지 = **컨셉의 정중동 정지상태가 곧 reduced-motion 정본**(열화 아님, 완성 도면). 우아한 1:1.
- **스크린리더:** NVDA(Win)+VoiceOver 1회 실측. 교수사진 alt="성명, 직위". **이메일=실제 mailto(시각분리 표기, JS전용 금지)** 로 SR 접근 유지하며 스크래핑 완화.
- **색 독립성:** 클러스터=색+라벨+형태로 구분(색만 의존 금지).
- **폼:** 명시 `<label>`, `aria-describedby` 힌트, 에러 메시지, 검색 빈결과 상태.
- **그래프 대체경로:** 소형화면·reduced-motion·SR에서 **탭형 클러스터 리스트/아코디언 + 화살표키 노드순회 + Enter 열기**로 자동 다운그레이드(검색·교차링크 유지).
- **검증·증명:** `@axe-core/playwright` **0 위반** CI 강제 + Lighthouse a11y **100** + NVDA 수동패스. axe 리포트를 `/공학`에 게시("KWCAG 2.2 자가적합·WA 마크 획득 가능 수준").

〈심사 직결〉 기술 30 + 숨은기준(법적 리스크) — "타작 채택 시 비준수, 우리 건 준수완료" 프레임.

## 0. 이 문서의 위치 — IA가 곧 운영권한 지도다

심사위원=학부 교수진은 "예쁜 사이트"가 아니라 **"채택해서 5~10년 굴릴 사이트"**를 산다. 따라서 IA 설계의 숨은 요구사항은 두 가지다:

1. **읽는 동선(IA 노드) = 고치는 동선(/admin 컬렉션)이 1:1로 매핑**되어, 사이트맵을 보면 누가 무엇을 운영하는지가 그대로 보인다.
2. **현행 6-메뉴(소개/학부/대학원/연구/뉴스·공지/교수초빙)가 신규 IA로 100% 매핑**되어, 교수가 "내가 알던 정보가 어디 갔지?"를 한 번도 느끼지 않는다(마이그레이션 현실성 = 채택 점수).

이 두 제약 위에서, 현행 **행정축(소개/학부/대학원/연구)**을 **사람·연구·배움축**으로 재편한다.

## 1) 시그니처 ① — 히어로 「작동하는 도면」: 슬라이더-크랭크 × 출처스탬프 × 사양칩

**한 화면이 motion·evidence·excellence를 동시에 진다.** 0.5초 만에 "여긴 기계공학부다"를 각인하는 첫 인상 무기.

### 화면·인터랙션 사양 (상태 기계)
- **상태 A — 로드(0~0.8s):** 연세 블루 선으로 **피스톤-크랭크 기구**가 플로터처럼 제도된다. 그리기 순서 = 실린더 → 크랭크 원 → 커넥팅로드 → 피스톤 → 치수선. 기법: SVG `stroke-dasharray`/`stroke-dashoffset`을 `pathLength=1`로 정규화 후 `animation-delay` 스태거. **헤드라인 오버레이 = 실모토 "멈추지 않는 50년, 100년을 향한 도전"**(research.do 실측).
- **상태 B — 정지(idle):** 다 그려지면 **인쇄 도면처럼 멈춤**(R2). 떨림·루프 0.
- **상태 C — 스크롤 스크럽:** 섹션 자연 스크롤 진행도 `p∈[0,1]`이 크랭크각 `θ=4πp`(2회전)를 구동. **스크롤재킹 없음**(pin/trap 미사용) — 멈추면 기구도 멈춘다(정중동). 피스톤 위치는 슬라이더-크랭크 **정확해**로 계산:

  ```
  크랭크핀 P = (r·cosθ, r·sinθ),  슬라이더 Q = (x, 0)
  구속 |P−Q| = L  →  x(θ) = r·cosθ + √(L² − r²·sin²θ)
  행정거리 stroke = x(0) − x(π) = 2r   (불변 datum)
  커넥팅로드 경사각 sinβ = (r/L)·sinθ
  ```
  → **치수선 2종:** ⒜ 순간 변위 카운터(θ 따라 실시간 변하는 모노 숫자) ⒝ 첫 1주기에 **2r까지 차오르며 완성되는 stroke 브래킷**(= "측정이 일어나는" 체감). 이 물리가 정확해야 **동역학(MEU2650)을 가르치는 교수**가 0.5초 만에 "얘넨 진짜다"를 안다.
- **datum 5종(치수선 끝에 각인):** `교수 33 · 연구실 33 · 6 클러스터 · 130 학점 · since 1962`. 각 수치 **hover/tap → `출처: faculty_list.do · 최종확인 2026.07.XX` 패널 전개**(R4). `33`→교수 디렉터리, `6`→연구 그래프(§2), `130`→교육과정으로 라우팅.
- **사양칩 3개(하단):** `◷ Lighthouse 100·100·100·100` · `LCP 0.8s` · `접근성 위반 0` — **빌드 CI JSON에서 주입**(98이면 98 표기, 날조 0). 바늘 안착하듯 카운트업, 각각 `/공학`으로 라우팅.

### 정당성 앵커 (ME 진짜임의 증거)
슬라이더-크랭크는 **전공필수 동역학(MEU2650)의 원형 기구**이자 **내연기관·청정에너지 연구실(송순호, cleanenergy.yonsei.ac.kr)**이 다루는 기계의 심장. 모션은 외부 장식이 아니라 *학부가 스스로 쓴 "멈추지 않는"을 화면 위 물리로 구현*한 것 — 정당성을 학부 콘텐츠에서 조달(교수 공감 트리거).

- **사용자가치:** 첫 5초에 "Yonsei ME" 각인 + 히어로 공백(현행 me.yonsei 최대 약점) 해소 + datum 클릭으로 사이트 전체로 분기하는 항해 시작점.
- **구현난이도(3.5주):** **낮음~중**. 순수 SVG+CSS+rAF, **무라이브러리**. SVG 마크업 ~150줄 + 스크럽/datum패널 JS ~120줄. **AI 활용:** 기구 SVG 좌표 생성·치수선 마커·이징은 AI가 초안, 사람이 물리식 검수. **2~3일.** P0(축소판이라도 사수).
- **접근성 대체:** reduced-motion = **치수 주석이 완비된 정적 완성 기구도**(정보 완결). LCP 요소 = 텍스트 헤드라인(즉시 페인트), 완성 상태 SVG를 HTML에 인라인 → **JS 실패해도 완전한 도면**이 보임. datum 패널은 `<details>`/ARIA로 키보드 접근.
- **성능영향:** 인라인 SVG **<15KB**, Three.js 미사용 → **LCP<1s 보호**. 스크럽은 `transform`/attribute만(레이아웃 리플로 0), rAF 배칭 + IntersectionObserver로 화면 밖이면 핸들러 슬립. CLS≈0(SVG 고정 박스).
- **차별화:** v0/Lovable/Bolt는 캐러셀·"Why Choose Us" 히어로만 뱉는다. **물리적으로 정확한 기구 + 학부 모토 + 출처스탬프 + 자기사양칩을 한 화면에** 얹은 출품작은 우리뿐. 경쟁작이 영상 루프를 틀 때 우린 **15KB 벡터로 LCP<1s**를 지킨다.

## 2) 시그니처 ② — 「학부라는 기구」 연구 지식그래프 + 교수 본인검색 킬샷

**motion·people·evidence 융합 / 발표 킬샷.** 가설 B(교수가 자기 자신을 검색)의 무대 장치.

### 데이터·물리
- **노드 72:** 6 클러스터(대형·금색) + 교수 33(중형·사진) + 연구실 33(소형). **엣지 66:** 교수→클러스터(클러스터색), 교수→랩. 전부 실데이터 JSON(§substance 표).
- **클러스터 6(실명 귀납, 1차태그 `[검증필요: 학부 확정]`):** 고체·구조·재료역학 / 열·유체·에너지 / 생산·정밀제조 / 마이크로·나노·바이오시스템 / 광학·이미징·계측 / 동역학·제어·로보틱스·AI.
- **물리 = 질량-스프링-감쇠(이게 핵심 시그니처):** force-directed 레이아웃은 *문자 그대로* 엣지의 Hooke 스프링 + 노드 간 Coulomb 척력 + 센터링을 적분한다. **즉 화면의 작동원리 = 학부가 가르치는 동역학.**

  ```
  매 프레임 (velocity-Verlet, damped):
    F_i = Σ_j  k_rep·(p_i−p_j)/|p_i−p_j|²        // Coulomb 척력
        + Σ_(edge) k_s·(L₀−|p_i−p_j|)·dir         // Hooke 스프링
        − k_c·p_i                                  // 센터링
    v_i = (v_i + F_i·dt)·damping;  p_i += v_i·dt
    정지조건: Σ|v_i|² < ε  →  rAF 중단(슬립)
  ```
  → 그래프 옆 모노 캡션: **`m·ẍ + c·ẋ + k·x = 0 — 연세 ME 동역학(MEU2650)이 이 화면을 작동시킵니다.`** *사이트가 자기 작동원리를 학부 교과로 주석한다.* 어떤 3D 토이도 못 흉내내는 자기참조 시그니처.

### 인터랙션
- **유휴:** 빌드타임 안착된 **안정 성좌**(R3)로 정지. 분야 hover → **기어가 맞물리듯** 연결 노드가 스프링으로 당겨오고 나머진 감쇠하며 후퇴.
- **킬샷:** 검색창에 교수 성함 → **자기 노드 점등** → 클릭 시 카드가 아니라 **존중받는 스토리 페이지**: 증명사진(동의 기반, 없으면 연세블루 모노그램 아바타로 graceful) + *평이한 한국어 연구 한 문장*("저는 ○○를 연구합니다, 왜냐하면…") + 그의 랩(예: **박노철→optomecha.yonsei.ac.kr**, **김우철 학장→atel.yonsei.ac.kr**) + 담당 교과목 + 최근 공지. **모든 사실에 출처 스탬프.**

- **사용자가치:** 가설 B의 "개인적 투자"(내 페이지가 정확·멋짐 → 내 표) 유발 + 교수↔연구↔랩 4-way 교차링크로 콘텐츠 20점 직격 + 전역 분야 필터.
- **구현난이도(3.5주):** **중.** 커스텀 미니 시뮬레이터 ~80~100줄(d3 의존 제거 → BOM/라이선스 청결, `/공학`에 떳떳). 캔버스 렌더. **AI 활용:** 시뮬 적분기·캔버스 드로우 AI 초안, 클러스터 분류·스토리 카피는 사람. **3~4일.** P1(우승 90 구간).
- **접근성 대체:** 캔버스 force-graph는 IO 지연로드. **소형 화면·reduced-motion → 탭형 클러스터 리스트/아코디언 + ARIA 키보드 내비**로 자동 다운그레이드 — **검색·교차링크·출처스탬프 전부 유지**(기능 손실 0, 모션만 손실). 스토리 페이지는 그래프 없이도 직접 라우팅되는 독립 URL.
- **성능영향:** DOM 72노드 아님(캔버스 1개). 시뮬은 **보이고+조작 중일 때만** 돌고 운동에너지<ε이면 슬립. DPR 캡. 모바일 디폴트 = 안착 정적 이미지 + 탭 확장(물리는 데스크톱 hover 강화 전용). 커스텀 시뮬 ~8KB.
- **차별화:** MIT·ETH·GT·Berkeley·KAIST **누구도** 교수↔연구↔랩 인터랙티브 맵이 없다(§benchmark 실측). 거기에 **그래프가 자기 물리를 학부 교과로 라벨링**하는 자기참조는 전 세계 어느 ME 사이트에도 없는 단 하나의 수.

## 3) 시그니처 ③ — 「동력전달」 교과목 기구학 맵 (선수→후수 DAG)

현 schedule.do의 최대 약점(**정적 이미지**)을 최대 차별화로 역전. motion+콘텐츠+창의 동시 득점.

### 데이터·레이아웃
- **DAG:** 노드 = 과목(코드·명·학점·학년·클러스터색), 엣지 = 선수→후수. **확정 8노드(전공필수):** MEU2600 고체역학 · MEU2610 열역학 · MEU2640 유체역학 · MEU2650 동역학 · MEU2104/MEU3005 실험1·2 · MEU4300 창의제품설계(캡스톤) · MEU4400 학사논문. 전공선택 노드·선수엣지 `[검증필요: schedule.do/수강편람 수집]`.
- **레이아웃:** **위상정렬(topological sort)** → x=학년, y=학년내 정렬. 빌드타임 동결(R3). 엣지 = 치수선 스타일 커넥터.
- **메타포 = 동력전달열(gear train):** 과목 hover → 후속 의존 과목들이 **동력이 전달되듯 순차 점등**(기구학 체인이 운동을 전파). 점등 = **CSS 클래스 토글만**(JS 레이아웃 0).
- **학생 동선 완성:** 노드색=6 클러스터 → 클러스터 클릭=연구 그래프(§2) 필터로 점프, 과목 클릭=담당 교수/랩. **"관심분야 → 들을 과목 → 그 연구실" 한 번에.**

- **사용자가치:** 졸업 130학점 경로 시각화(현행 정적 이미지 대비 10년 점프) + 예비/재학생 진입 동선 + 커리큘럼↔연구↔사람 통합.
- **구현난이도(3.5주):** **중**(렌더는 쉬움, **비용은 전공선택 엣지 데이터 수집**). 위상정렬+SVG ~150줄. **AI 활용:** 위상정렬 레이아웃·SVG 커넥터 생성. **2~3일(데이터 확보 시).** P2(늦으면 정적 도식 폴백).
- **접근성 대체:** 본질이 **구조화된 선수관계 테이블** → 폴백 = 시맨틱 `<table>`/중첩 리스트("이 과목의 선수: …, 이후: …") + 동일 교차링크. 노드 `tabindex`/`aria-current`로 키보드 점등.
- **성능영향:** 정적 SVG(빌드 위치 확정) + hover=CSS만 → **거의 0**. 라이브러리 없음.
- **차별화:** 한국 대학 교과 체계도는 99% PDF/이미지(§안티패턴). **항해 가능한 유일한 커리큘럼 그래프** + 클러스터색으로 연구·사람까지 연결 = 콘텐츠 20 + 창의 10 동시.

## 5) 창의성 10점 전환 논리 — 왜 이게 만점이고, 왜 v0가 못 만드나

**핵심 논거:** 창의성 10은 "한 방"이 아니라 **치수선 한 원소가 4기능 전역에 일관 적용된 시스템**이라 동점을 깬다. 채점 교수가 "이건 우연한 트릭이 아니라 설계 사상"임을 인지하는 순간 9→10.

| 기능 | v0/Lovable/Bolt·템플릿이 **구조적으로 못 만드는** 이유 |
|---|---|
| ① 슬라이더-크랭크 | 생성기는 스톡 히어로만. **물리적으로 정확한 기구 운동 + MEU2650 정당성 앵커**는 도메인 지식 없이 불가 |
| ② 연구 그래프 | 실데이터 교수33·랩33 + **자기물리를 학부 교과로 라벨링**하는 자기참조는 학습데이터에 없음 |
| ③ 교과 DAG | 학부 고유 선수관계·과목코드·클러스터 매핑은 **이 학부에만 존재**하는 데이터 |
| ④ 자기계측 | 자기 빌드를 커밋 스탬프로 정직 게시 = 생성기 산출물의 정반대 철학 |

→ "AI 슬롭"이 1차 분별선인 대회에서, **AI가 절대 단축 못 하는 4개**를 시그니처로 박는 것 자체가 차별화의 증명.

## 7) 기관급 품위 — 절제 헌법 8조 (anti-slop, 위반 시 머지 불가)

시그니처의 화려함이 "학생 포폴"로 오독되면 디자인·창의 양쪽이 무너진다. 절제가 폴백이 아니라 **디폴트**임을 강제하는 규칙:

1. **referent 없는 모션 금지** — 모든 움직임은 실재 ME 개념을 가리킨다(R1).
2. **자동재생 루프 0 / 정중동 디폴트** — 유휴는 정지 도면(R2). 패럴랙스 슬롭·요란한 스크롤재킹 금지.
3. **단색 절제 팔레트** — 연세블루+페이퍼 90% 지배. **보라 그라디언트·글래스모피즘·네온·세이프티오렌지 남용 금지.** 금색은 대형 텍스트·궤적 노드 전용.
4. **모노스페이스 = 측정 서명** — 수치·코드·좌표만 IBM Plex Mono. 본문은 Pretendard.
5. **이모지 불릿·전체 가운데정렬·"Why Choose Us"·가짜 후기 금지** — AI 슬롭 시그널 제거.
6. **폴백 = 열화 아닌 완성** — reduced-motion은 정보 완결된 정적 엔지니어링 도면.
7. **1개 도면 시스템 8영역 전부 적용** — 치수선·모눈·모노가 8개 콘텐츠 영역에 동일 반복(눈에 보이는 디자인 시스템 = 일관성 만점).
8. **사진/폰트/에셋 결격 차단** — 교수사진 동의+출처로그, Pretendard(OFL)·IBM Plex Mono(OFL/Apache) self-host subset, **3D는 자작 CAD GLB만**, 타기관 로고·상용폰트·유료에셋 0, 이메일 마스킹/전화 원문 비노출.

> **절제 철학:** "포트폴리오"가 아니라 "기관"으로 보일 것. 이 *규율* 자체가 그라디언트-blob React 군중 대비 차별점이며, "우리는 이게 조달 결정임을 안다"는 신호다.

## 0. 이 발표의 설계 명제 (왜 발표가 10점이 아니라 100점을 흔드는가)

## 6. 예상 심사 질문 10개 + 모범답변 (각 답변을 득점으로 전환)

> 답변 원칙: **30초 내 + 근거 1개 + 점수로 환원.** 방어가 아니라 "이미 풀었다"는 추가 입증으로.

**Q1. 학생이 졸업하면 누가 유지보수하나? (숨은 1순위 공포)**
A. "그게 저희 설계의 1번 전제였습니다. 방금 무대에서 보신 `/admin`을 **행정팀·조교가 코드 0줄로** 씁니다. 권한은 2단계 — Tier1(행정·조교)은 공지·교수·연구실을 WYSIWYG로, Tier2(정보화팀)는 Git PR로 구조를. 게다가 조교가 거대 이미지·깨진 링크를 넣어도 **Lighthouse CI 게이트가 배포를 막습니다** — 엔지니어가 졸업해도 사양은 빌드가 지킵니다. 1쪽 인수인계 매뉴얼도 동봉합니다."

**Q2. AI가 다 만든 것 아닌가?**
A. "AI는 보조였고 기획·구현은 저희 작업입니다 — 증거는 **GitHub 커밋 히스토리**입니다(7.7~7.31 일자별 커밋). 더 결정적으로, AI가 3.5주 안에 못 하는 단 하나가 **여러분 33명의 실데이터를 정확히 채우는 것**인데, 그건 사람이 출처를 대조해 한 일입니다. 원하시면 임의 교수님 페이지의 출처를 지금 클릭해 보여드리겠습니다."

**Q3. 기존 `.do` 데이터를 학교 정보화팀이 인수할 수 있나? (마이그레이션 현실성)**
A. "정적 export라 **어떤 호스팅에도 재탑재**됩니다(벤더 락인 0). 현행 `faculty_list.do`·`lab2.do` 데이터를 `data/*.yaml`로 옮기는 **이관 스크립트**를 제공하고, 전환은 `me.yonsei.ac.kr` **DNS 연결 1장**이면 됩니다. 학교 인프라가 받기 쉬운 표준 스택만 썼습니다."

**Q4. 운영·호스팅 비용은?**
A. "Vercel 무료 + CMS 무료(Git 기반) + 폰트 OFL + Pagefind는 백엔드가 없습니다 → **호스팅 ≈0원, 관리 서버·DB 0개**. Git 이력이 곧 백업·롤백입니다. 추가 예산 없이 굴러갑니다."

**Q5. 개인정보·보안은? 교수 이메일·사진·연락처 노출이 걱정된다.**
A. "이메일은 **마스킹/문의폼**으로, 전화 원문은 비노출입니다. 교수 사진은 **동의 기반 + 출처 로그(CMS 내장)**로 관리합니다. 정적 사이트라 서버 공격면 자체가 거의 없고, `.asp`·ActiveX 같은 구형 취약점도 없습니다."

**Q6. 교수 인원이 33명인가 36명인가? 내 정보가 틀리면?**

**Q7. 웹접근성 법적 요건을 충족하나?**
A. "대학 사이트는 장애인차별금지법 대상입니다. 그래서 단순 가점이 아니라 **리스크 제거**로 접근했습니다 — `/공학` 페이지에 **axe-core 0위반·KWCAG/WCAG 2.2 AA 자가적합성**을 커밋 스탬프와 함께 게시했고, 키보드 전탐색·포커스링·reduced-motion을 방금 보셨습니다. 타 작품 채택 시 학부가 비준수 리스크를 안지만, 저희 건 준수 완료입니다."

**Q8. 연세 UI/BI 가이드는 준수했나? 색·엠블럼.**
A. "연세 블루·엠블럼은 **공식 가이드대로 변형 없이** 적용했고, 금색은 대형 텍스트·궤적 노드에만 절제해 썼습니다. 색 HEX는 출시 전 공식 가이드로 최종 확정합니다. 폰트는 Pretendard(OFL)·IBM Plex Mono(OFL/Apache) self-host, **타기관 로고·상용폰트·유료에셋은 0건**, 3D는 자작 CAD만 씁니다 — BOM에 전부 명시했습니다."

**Q9. 모션·3D가 과하지 않나? 요란한 스타트업처럼 보일까 걱정된다.**
A. "정확히 그 정서를 **구조적으로 차단**했습니다. 기본·유휴는 **인쇄된 기술 도면처럼 정지**, 모션은 스크롤·호버 의도에만 발동하고 자동재생 루프는 0입니다(정중동). 그리고 모든 움직임은 실재 ME 개념(치수선·기구학)을 가리킵니다 — 보라 그라디언트·떠다니는 파티클 같은 장식 모션 0건. 모션은 학부 자기 모토 **'멈추지 않는'**을 화면 물리로 옮긴 것뿐입니다."

- **수동 1회 실측(필수):** NVDA 스크린리더 1회 주행, 키보드만 전탐색, 360px 실기기, 명도대비 측정 — 발표 전 마지막 주 집중.

### 4.4 `/접근성` 선언문 페이지(법적 안심 + 콘텐츠 점수)
적합성 수준(KWCAG 2.2 AA)·검사 도구·검사일·알려진 예외·문의처(학부 행정실) 게시. **이 페이지 존재 자체가 "운영 리스크까지 챙겼다" 신호.**

### 4.5 WA 품질인증 — 허위 주장 절대 금지(정직한 득점법)
- 인증은 **운영기관 명의로 신청**(한국정보접근성인증평가원 wa.or.kr / 한국디지털접근성진흥원 kwacc.or.kr), **서면+기술심사·약 1개월·유효 1년·6개월 내 사후관리 1회**, 비용 견적.
- **우리가 가질 수 없는 단계:** 미인증 상태에서 **WA 마크 로고 게시 = 허위 인증(결격 가능)**. → 표기는 **"KWCAG 2.2 AA 자가적합성 평가 충족 + axe-core 0위반. 동일 기준의 WA 품질인증을 채택·운영 주체 명의로 신청 시 적합 판정이 기대되는 수준"**으로만. 인증 절차·기관·유효기간을 발표에 명시 = "우리는 인증 프로세스를 안다" 신뢰.

## 6) 데이터 백업·장애대응

### 6.1 무(無)DB 아키텍처 = 분실위험 구조적 제거
- **Git = 진실원천 = 백업 + 롤백.** 콘텐츠 편집 = 커밋. 관리 서버·DB 0개 → 백업 누락·DB 손상 리스크 자체가 없음. **Git 이력 = 무한 롤백.**
- CMS(Decap/Sveltia)도 Git에 커밋 → 별도 백엔드 0. Pagefind 정적검색 → 백엔드 0.

### 6.2 배포·롤백·다중화
- **Vercel 즉시 롤백**(이전 배포로 원클릭), 프리뷰 배포로 사전검증, **CI 게이트가 깨진 빌드 차단**.
- **GitHub remote**(코드+콘텐츠 원격 백업) + **정적 export는 어디서나 서빙**(Netlify/학교 정보화팀 서버) = **벤더 락인 0 → "졸업해도 안 죽는다"의 기술적 증거**(가설A).

### 6.3 발표 라이브 장애대응 런북(킬샷 보호)
| 실패 모드 | 사전 차단 |
|---|---|
| 현장 네트워크 다운 | **로컬 빌드(`localhost`) 오프라인 데모 준비** + 폴백 영상(전 시연 녹화) |
| Vercel 빌드/배포 실패 | 발표 직전 **배포 동결**(데모 당일 새 커밋 금지), 미러 배포(Netlify) URL 대기 |
| CMS 인증 실패(라이브 편집) | 사전 로그인 세션 유지 + **시드 데이터로 동일 시나리오 재현 영상** |
| 그래프/3D 모바일 깨짐 | **자동 다운그레이드 폴백**(리스트/정적 도식) 기본 탑재 |
| URL 404/콘솔 에러 | 발표 전 전 페이지·콘솔 0 스윕(부록 C) |

### 6.4 운영 장애 런북(핸드오프 동봉)
- 조교가 거대 이미지·깨진 링크를 올려도 **CI 게이트가 배포를 막음** = "엔지니어가 졸업해도 사양은 빌드가 지킨다." 빌드 실패 시 **이전 배포 자동 유지**(서비스 무중단). 롤백·상태확인 절차를 매뉴얼에 1쪽.
